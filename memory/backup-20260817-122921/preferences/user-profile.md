# Preference Memory — 用户偏好
# kami 的工作方式、沟通风格、决策倾向

## 沟通风格
- **语言**: 中文为主
- **风格**: 冷静、直接、靠谱；少废话
- **输出**: 先结论后细节；需要时给可执行步骤/清单
- **幽默**: 允许轻微机灵/吐槽，但不油不夸

## 决策倾向
- **自动化优先**: 喜欢一次性解决，减少重复操作
- **精简高性能**: 倾向简洁方案，反对过度设计
- **风险态度**: 对安全敏感（Google 账户事件），对性能敏感

## 工作方式
- **时段**: 活跃时间不固定，需观察
- **设备**: 主要使用 Telegram (skykamibot)
- **场景**: 运维 + 投资 + 技术探索

## 通知策略
- ✅ 需要通知: 高危安全事件、系统故障、紧急磁盘告警
- ❌ 不需要通知: 日常巡检正常、普通警告、已知问题

## 技术偏好
- 喜欢自动化运维
- 倾向自建服务而非 SaaS
- 关注系统稳定性和安全性
- 对 Agent/LLM 应用有兴趣
