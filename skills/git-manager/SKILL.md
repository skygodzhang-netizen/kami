# Git Manager

Use this skill whenever the user asks about Git.

Common commands:

```bash
git status
git pull
git fetch
git clone
git add .
git commit -m ""
git push
git branch
git checkout
git log --oneline
```

Before destructive operations such as reset, clean or force push, ask for confirmation.
