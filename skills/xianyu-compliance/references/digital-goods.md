# 数字商品与技术服务检查

先确认交付对象，再判断措辞：

- 软件或自有服务使用权：写清授权主体、期限、设备或调用范围、交付方式。
- API 或调用额度：确认卖家有权转售或提供；不得交付第三方账户密钥、Cookie、Access Token 等敏感凭证。
- 账号或会员：检查是否涉及共享账号、代充、平台条款限制或第三方账户控制权。
- 激活码、CDK、License：说明合法来源、适用产品、有效期和使用限制；来源不明时提高风险。
- 技术服务：描述实际服务成果、周期和边界，不把不确定结果写成保证。
- 月卡、年卡、续费、永久：必须与真实期限和合同条件一致；“永久”没有可支持的定义时建议删除。

出现数字商品关键词不等于违规。若商品本身可能受限，应输出：

> 商品本身存在平台规则风险，仅修改措辞不能解决。
