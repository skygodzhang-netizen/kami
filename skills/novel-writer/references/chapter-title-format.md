# 章节标题格式规范 / Chapter Title Format Standards

**版本**: 1.0.0 (2026-04-16)  
**使用场景**: 确保所有章节标题风格一致

---

## 标题格式

**标准格式**: `[关键词]！[结果/状态]`

| 组成部分 | 说明 | 示例 |
|---------|------|------|
| **关键词** | 核心事件/物品/概念 | 血脉玉、九道禁制、魔宫令牌 |
| **！** | 感叹号分隔符 | 必须使用中文感叹号 |
| **结果/状态** | 事件结果或当前状态 | 敖灵救命、生门死门、通过禁制 |

## 标题一致性检查

生成新章标题时，检查：
1. 是否包含关键词？
2. 是否使用感叹号分隔？
3. 是否包含结果/状态？
4. 是否与最近3章风格一致？

### 检查脚本

```python
def check_title_format(title):
    """检查标题格式"""
    if '！' not in title:
        print("❌ 错误：标题必须使用'！'分隔")
        return False
    
    parts = title.split('！')
    if len(parts) != 2:
        print("❌ 错误：标题必须包含两部分（关键词！结果）")
        return False
    
    keyword, result = parts
    if len(keyword) < 2 or len(result) < 2:
        print("❌ 错误：关键词和结果都不能太短")
        return False
    
    print("✅ 标题格式正确")
    return True

# 使用示例
check_title_format("三重试炼！魔祖认可")  # ✅
check_title_format("三重试炼")  # ❌
check_title_format("三重试炼，魔祖认可")  # ❌
```

### 批量修正

当发现标题风格不一致时，需要同时修正：
1. `final/chapter-XXX-final.md` 中的标题
2. `draft/chapter-XXX-draft.md` 中的标题  
3. `outline/chapter_XXX_outline.md` 中的标题
