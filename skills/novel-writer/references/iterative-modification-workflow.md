# 迭代修改工作流 / Iterative Modification Workflow

**版本**: 1.0.0 (2026-04-14)  
**使用场景**: 草稿确认后、终稿入库前，用户可能提出多轮修改意见

---

## 核心发现 (2026-04-14)

### 文件保存时机

⚠️ **关键**: 大纲/草稿文件**必须**在 `confirm_step` 之前保存

| 文件类型 | 保存路径 | 保存时机 |
|---------|---------|---------|
| 章节大纲 | `outline/chapter_XXX_outline.md` | 大纲生成后，confirm_step 之前 |
| 章节草稿 | `draft/chapter-XXX-draft.md` | 草稿生成后，confirm_step 之前 |
| 修改后草稿 | `draft/chapter-XXX-draft.md` | 每次用户修改后，重新保存 |

### 多轮修改流程

```
草稿生成 → 保存草稿文件 → 用户审阅 → 提出修改 → 执行修改 → 重新保存 → 用户确认 → (可能重复) → 终稿入库
```

**典型修改轮数**: 2-3 轮

## 常见修改类型及处理方案

### 1. 逻辑漏洞补全

**示例**: "魔君为什么不追赶主角？"

**问题**: 剧情存在逻辑缺口，读者会质疑

**处理方案**:
- 在草稿阶段补充设定解释
- 不要留到终稿或后续章节圆场
- 解释应简洁，不要打断节奏

**修改示例**:
```
【原稿】七大魔君怒啸连连，却只能眼睁睁看着苏辰远去
【修改】七大魔君怒啸连连，身形刚动却被混沌锁链拽回——他们需镇守秘境核心，脱身不得
```

### 2. 角色动作一致性

**示例**: 禄存星君用了文曲星君的黑雾技能

**问题**: 角色技能/武器混用，破坏设定一致性

**处理方案**:
- 修改前检查角色卡 (`character_cards.json`)
- 确保每个角色的动作匹配其武器/技能
- 建立角色技能速查表

**角色技能速查表**:
| 角色 | 武器/技能 | 攻击方式 |
|------|----------|---------|
| 禄存星君 | 长戈 | 物理穿刺、星力灌注 |
| 文曲星君 | 黑雾 | 腐蚀、幻术、精神攻击 |
| 廉贞星君 | 双剑 | 快速连击、剑阵 |

### 3. 描写模式突破

**示例**: 强者出场描写公式化 (身高→脸→武器→气场)

**问题**: 读者审美疲劳，缺乏新意

**处理方案**:
- 从感官体验切入 ("神识被咬了一口")
- 使用声音/幻觉/感官错位作为入口
- 留白制造张力，不一次性披露全部信息
- 控制信息密度 (合并/省略/动作转换)

**修改示例**:
```
【公式化】他身高九尺，面如冠玉，手持长枪，气势逼人
【突破】先闻其声——长枪拖地的金属刮擦声从黑暗深处传来，
       一下，一下，敲在神识上。苏辰眯起眼，只看见枪尖
       挑破黑暗时带起的一串火星。
```

### 4. 跨章比喻重复

**示例**: 第 32 章用"轻如鸿毛"，第 33 章又用

**问题**: 连续章节修辞重复，显得词汇贫乏

**处理方案**:
- 检查最近 3 章的比喻/修辞
- 替换为不同表达
- 建立修辞使用记录

**替换示例**:
| 原表达 | 替换为 |
|-------|-------|
| 轻如鸿毛 | 动作轻盈得没有发出半点声响 |
| 快如闪电 | 身影一晃便到了眼前 |
| 重如泰山 | 每一步都踩得地面下沉三分 |

---

### 5. 字数超标压缩

**示例**: 草稿生成后字数6275字，超出3800上限

**问题**: 内容冗余，对话过多，需要精简

**处理方案**:
- 采用"对话转叙述"策略：将描述性对话（规则说明、背景介绍）改为间接叙述
- 保留关键对白：情感冲突、决策时刻、角色性格展示的对白保留
- 合并重复信息：同一信息在不同对话中重复出现时，只保留一处
- 删除冗余修饰：删除不影响剧情的形容词和副词

**修改示例**:
```
【原稿 - 对话过多】
"问心路共有一百阶，"土行解释道，"踏上后修为会被压制到金仙境。"
"每走一步都会面临幻象考验？"苏辰问道。
"是的，"土行点头，"唯有本心澄澈、真诚不欺者，方能通过。"
"这是规矩，不因实力而破例？"
"正是如此。"

【修改 - 转为叙述】
土行解释道，问心路共有一百阶，踏上后修为会被压制到金仙境，
每走一步都会面临幻象考验。唯有本心澄澈、真诚不欺者方能通过，
这是规矩，不因实力而破例。
```

**效果**: 字数从6275字压缩至3762字，对话比例从44%降至36%

## 修改后验证清单

| 检查项 | 验证方法 | 通过标准 |
|-------|---------|---------|
| 字数范围 | `len(re.findall(r'[\u4e00-\u9fff]', draft))` | 2600-3800 |
| 无新增重复段落 | 执行去重检查代码 | 无重复 |
| 逻辑漏洞已补全 | 审阅用户指出的问题 | 全部解决 |
| 角色动作一致 | 对照角色卡检查 | 无混用 |
| 描写无公式化 | 检查强者出场描写 | 从感官切入 |
| 无比喻重复 | 检查最近 3 章 | 无重复修辞 |
| 无英文混入 | 全文搜索常见英文词 | 无英文 |
| 结尾无套路重复 | 检查章节结尾方式 | 独特结尾 |
| **省略号数量** | `text.count('…')` | <30次 |
| **对话占比** | 对话字数/总字数 | 20-60% |
| **平均段落长度** | 总字数/段落数 | >15字 |
| **系统提示次数** | 统计【系统提示】 | 2-3次 |

## 番茄小说质量检查自动化

使用 `scripts/tomato_quality_checker.py` 自动检查：

```bash
python scripts/tomato_quality_checker.py draft/chapter-XXX-draft.md
```

检查项：
- 字数范围 2600-3800（中文+标点）
- 对话占比 20-60%
- 省略号 < 30次
- 平均段落 > 15字
- 系统提示 2-3次

Python调用示例：
```python
from scripts.tomato_quality_checker import analyze_chapter, check_quality, print_report

with open('draft/chapter-086-draft.md', 'r', encoding='utf-8') as f:
    text = f.read()

metrics = analyze_chapter(text)
quality = check_quality(metrics)
print_report(metrics, quality)
```

## 去重检查代码

```python
def check_duplicates(draft):
    lines = draft.split('\n')
    seen = {}
    duplicates = []
    for i, line in enumerate(lines):
        if line.strip() in seen and len(line.strip()) > 20:
            duplicates.append((line.strip(), seen[line.strip()], i))
        else:
            seen[line.strip()] = i
    if duplicates:
        print("发现重复内容，需手动清理")
        for text, first, second in duplicates:
            print(f"行{first}和行{second}重复：{text[:50]}...")
    return duplicates
```

## 英文混入检查代码

```python
def check_english(draft):
    common_english = ['pointed', 'OK', 'ok', 'the', 'a', 'an', 'is', 'are', 'was', 'were']
    found = []
    for word in common_english:
        if word in draft:
            found.append(word)
    if found:
        print(f"发现英文词汇：{found}")
        for word in found:
            # 显示上下文
            import re
            matches = re.finditer(rf'\b{word}\b', draft)
            for m in matches:
                start = max(0, m.start() - 30)
                end = min(len(draft), m.end() + 30)
                print(f"  '{word}' at position {m.start()}: ...{draft[start:end]}...")
    return found
```
