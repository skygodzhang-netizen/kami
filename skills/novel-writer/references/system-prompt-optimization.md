# 系统流小说系统提示优化指南

## MINIMAL 原则下的系统提示处理

**原则**: 每章系统提示控制在 2-3 个，避免【】格式刷屏，保持叙事流畅。

---

## 优化模式

### 模式 1: 显式→隐式转换

将显式的【】系统提示转换为叙事描述。

**转换前**:
```
【时间法则感悟：50%→70%，解锁"时间之眼"】
系统的提示音在他意识中响起。
```

**转换后**:
```
时间法则感悟从50%提升至70%，解锁"时间之眼"——被动技能，偶尔能看到未来片段。

系统的提示在他意识中响起，但苏辰已经无暇顾及。
```

### 模式 2: 感知化描述

将系统数据转化为角色的感知体验。

**转换前**:
```
【检测到宿主与烛九阴建立师徒羁绊，奖励：时间亲和度+15%】
```

**转换后**:
```
苏辰感觉到时间亲和度提升，与烛九阴的师徒羁绊实质确立。
```

### 模式 3: 内心独白替代

将系统警告转化为角色的内心判断。

**转换前**:
```
【警告：检测到双重准圣威胁，建议立即突围】
系统的警告声响起。
```

**转换后**:
```
双重准圣的威胁让苏辰心头一沉，必须立即突围。
```

---

## 保留系统提示的场景

以下情况可保留 1-2 个【】格式提示:

1. **重大升级/突破**: 系统升级、新功能解锁
2. **关键道具获取**: 始祖之卵认主、重要物品
3. **危机警告**: 生死关头的紧急提示

**示例** (第83章系统升级):
```
【系统升级完成！解锁新功能：
1. 法则吞噬（可吞噬其他法则提升感悟）
2. 始祖之卵共鸣地图（显示其他8枚卵位置）
3. 系统自检（显示与混沌魔神关联度）】
```

---

## 质量检查清单

- [ ] 【】格式提示 ≤ 3 个/章
- [ ] 系统关键词出现 ≤ 5 次/章
- [ ] 提示内容已融入叙事或转化为角色感知
- [ ] 重大事件保留 1-2 个显式提示（可选）

---

## 常见错误

### 错误 1: 过度转换
将应该保留的重大提示也转换了。

**错误**:
```
苏辰感觉到系统升级了，多了一些新功能。
```

**正确**:
```
【系统升级完成！解锁新功能：法则吞噬、始祖之卵共鸣地图、系统自检】
```

### 错误 2: 转换不彻底
仍保留明显的系统提示痕迹。

**错误**:
```
系统提示他时间法则提升了。
```

**正确**:
```
他感觉到对时间的理解更加深刻，时间法则的感悟在飞速提升。
```

## 实战案例

### 第88章优化实例

**原始版本** (6处系统提示):
1. 【时间法则感悟：50%→70%，解锁"时间之眼"】
2. 【检测到宿主与烛九阴建立师徒羁绊，奖励：时间亲和度+15%】
3. 【警告：检测到双重准圣威胁，建议立即突围】

**优化版本** (0处【】提示):
1. "时间法则感悟从50%提升至70%，解锁'时间之眼'——被动技能..."
2. "苏辰感觉到时间亲和度提升，与烛九阴的师徒羁绊实质确立。"
3. "双重准圣的威胁让苏辰心头一沉，必须立即突围。"

**效果**: 保持MINIMAL原则，叙事更流畅，角色主动性更强。

## 快速修复脚本

```python
# 检查系统提示数量
import re

bracket_prompts = re.findall(r'【[^】]+】', content)
if len(bracket_prompts) > 3:
    print(f"警告：检测到 {len(bracket_prompts)} 处【】格式提示，建议优化")
```
