# 小说创作质量检查清单

## 元规则（最高优先级）

> **当情感/创意冲击力与清单冲突时，优先服从创作直觉，质量检查仅作为复盘参考工具。**

质量检查清单的目的是辅助创作，而非束缚创作。在以下情况下，可豁免特定检查项：
- 情感高潮章节需要更强的抒情表达
- 创意突破需要尝试新的叙事手法
- 特定场景需要打破常规以达成冲击效果

**豁免原则**：
1. 先创作，后检查
2. 检查发现问题时，评估是否为创意需要
3. 如为创意需要，保留并记录；如为失误，修正
4. 终稿前统一复盘，确保整体质量

## 用户指令规范

### 删除指令 "删"
- **含义**：COMPLETE deletion（完全删除）
- **执行方式**：
  - 不得保留任何部分内容
  - 不得修改/改写后保留原意
  - 不得询问"是否保留XX部分"
  - 立即执行绝对删除
- **示例**：用户说"删" → 立即删除指定内容，不保留任何痕迹

### Workflow合规要求
1. **执行前复述**：每次执行Skill前必须复述关键步骤
2. **分阶段确认**：每个阶段完成后必须获得用户确认
3. **禁止跳步**：不得跳过或简化任何步骤
4. **阶段完成确认**：必须明确确认阶段完成（如"终稿已保存至final/chapter_XXX_final.md"）

## 反煽情检查

### 豁免条款
**情感高潮章节可豁免本项检查，但需保持通过行动和对话展现情感的底层逻辑。**

豁免条件：
- 章节处于情感爆发点（如生死离别、重大承诺、真相揭露）
- 抒情表达服务于剧情需要，非为煽情而煽情
- 情感展现仍以行动和对话为主，内心独白为辅

豁免限制：
- 不得使用AI味词汇（"终于明白"、"恍然大悟"等）
- 不得出现排比句式堆砌
- 不得主题先行总结

---

### 常见错误模式
- 结尾大段内心独白："无论前方有什么在等待着，他都不会退缩…"
- 排比句式煽情："身后，有…身旁，有…前方，有…"
- 主题先行："这，就是他的道。绝对自主，但绝非孤独。"
- 过度修辞："如同巨人的尸骨横亘在大地上"、"如同液体般流淌"
- 形容词堆砌："灰蒙蒙的"、"狂暴而混乱"、"黯淡无光"

### 修正方法
1. 保持克制，用行动代替抒情
2. 使用"最简单文字，描绘最真实情况"（voice_config.json核心要求）
3. 删除比喻修辞，改用直接描述
4. 简化形容词，保留必要修饰即可

## 剧情逻辑连续性检查

### 常见错误模式
- 三人分散坠落后写"团队夜话"（ physically impossible ）
- 角色在A地却写其在B地的行动
- 时间线混乱，前因后果颠倒

### 修正方法
1. 创作前回顾上一章结尾状态（角色位置、状态、关系）
2. 绘制简单时间线：谁在哪里，能做什么，不能做什么
3. 如剧情需要聚集，必须先写"寻找/汇合"过程
4. 复杂场景拆分多章，避免逻辑跳跃

### 案例
第90章原计划写"团队夜话"，但第89章结尾四人已分散坠落。修正为第90章写"失散与寻觅"，第91章再写"重聚与真相"。

## 文件命名规范检查

### 常见错误模式
- 使用下划线：chapter_090_draft.md
- 其他章节使用连字符：chapter-090-draft.md

### 修正方法
1. 创建文件前先用ls检查现有文件命名格式
2. 严格遵循项目既有命名规范
3. 连字符 vs 下划线必须统一

## AI味风险识别与修正

### 常见AI味模式
1. **排比式总结**："罗睺在布局。帝江在布局。而他，必须..."
2. **抽象情绪宣告**："第一次感到……孤独"（用省略号煽情）
3. **上帝视角总结**："他必须在这两个布局中找到生路"
4. **元叙述/作者备注**：正文出现"第X章"、"本章"、"上一章"等管理词
5. **陈词滥调**："无论前方有什么，他都不会退缩"

### 修正方法
1. **排比式总结** → 改为具体情境描述（谁在哪里，面临什么）
2. **抽象情绪宣告** → 改为身体反应和动作（低头看胸口、手指收紧、不知往哪走）
3. **上帝视角** → 改为角色受限视角（看不到出口，感应不到信号）
4. **元叙述** → 删除所有"章/卷/篇/上章/下章/本章/下一章/上一章"
5. **陈词滥调** → 用具体选择代替口号（迈步向前 vs "不会退缩"）

### 案例
**修正前（AI味）**：
```
罗睺在布局。
帝江在布局。
而他，必须在这两个布局中找到生路。
苏辰站在时间流光中，第一次感到……孤独。
```

**修正后（人味）**：
```
罗睺要恢复混沌魔神的力量，帝江想要时空双卵。
而他，被困在时间的缝隙里，既找不到出口，也感应不到她的位置。
苏辰低头看着胸口，那里已经恢复平静。他试着催动混沌之力感应，但逆鳞像一块普通的鳞片，再也传不回任何波动。
他站在原地，忽然不知道该往哪边走。
```

## 设定一致性检查

### 常见错误模式
- 角色卡写"复活混沌魔神"，正文写"恢复混沌魔神的力量"
- 阵营立场前后矛盾（如麒麟族保守派突然关心"儿女情长"）
- 角色定位偏移（如麒天变成"情敌"而非"战友"）
- **plot_engine设定冲突**：擅自修改plot_engine中明确的设定（如将"三天"改为"半个时辰"）
- **添加未授权的设定**：在正文中新增plot_engine未提及的设定（如"时间之卵分裂成两半"）
- **洪荒设定偏离**：鸿钧干预个人命运、罗睺大战后不下线等不符合洪荒世界观的行为

### 修正方法
1. 生成草稿前必读 character_cards.json 确认角色设定
2. 涉及关键设定（如罗睺目标、系统秘密）必须与配置一致
3. **必须读取plot_engine对应章节规划**，确保不偏离既定设定
4. 发现偏差立即删除重写，禁止打补丁
5. 阵营立场必须符合 faction_config.json 定义
6. **洪荒世界观设定必须合规**：
   - 鸿钧道祖：超然无为，顺应天道，不直接干预个人命运
   - 罗睺：魔祖，与鸿钧大战后应下线（重伤/封印/逃遁）
   - 准圣大战：结果应模糊处理，不写明胜负细节
   - 天道：修复创伤、维持秩序，不针对个人

### 强制检查点
- [ ] 罗睺目标：恢复混沌魔神的力量（非"复活"）
- [ ] 系统关联度：87%（第94章状态）
- [ ] 苏辰-敖灵关系：绝对信任建立（第94章）
- [ ] 三族同盟：龙族-凤族-麒麟族（第91章确立）
- [ ] **plot_engine设定一致性**：时间线、关键道具状态、角色能力必须与plot_engine一致
- [ ] **洪荒设定合规性**：鸿钧超然不干预、罗睺大战后下线、天道修复不针对个人

## 角色定位准确性检查

### 常见错误模式
- **关系定位错误**：将竞争对手/战友写成爱情 rival（如麒天是苏辰的竞争对手/战友，不是情敌）
- **阵营立场错误**：中立阵营角色突然关心"儿女情长"（如麒麟族不会提及" romantic affairs "）
- **人设偏离**：谨慎果断的角色说出感性台词（如苏辰说"等我"、"会活着回去"）

### 修正方法
1. **创作前必读character_cards.json**，确认每个角色的：
   - 与主角的关系类型（竞争/合作/中立/敌对）
   - 阵营立场和价值观
   - 核心性格特征
2. **对话必须符合角色立场**：中立阵营不谈私情，竞争关系不煽情
3. **禁止不符合人设的独白**：功能性思维角色（如苏辰）不应有感性内心独白
4. **发现定位偏差立即删除重写**，禁止打补丁修正

### 关键角色定位示例
- **麒天**：竞争对手/战友，NOT love rival
- **敖灵**：战友/绝对信任关系，NOT需要被拯救的弱女子
- **苏辰**：谨慎、果断、利益至上、功能性思维，NO sentimental monologues
- **麒麟族（ Shi Qilin ）**：中立保守，NO "romantic affairs" mentions
- **鸿钧道祖**：超然无为，顺应天道，NO direct intervention in personal fate
- **罗睺**：魔祖，与鸿钧大战后应下线（重伤/封印/逃遁），NO post-battle presence

## 章节标题风格规范

### 常见错误模式
- 过于直白/功能性标题："真相大白·升级"、"失明与恐慌"
- 缺乏情感张力和悬念
- 像大纲条目而非章节标题

### 正确风格（evocative）
- 使用感叹号分隔："魔神容器！杀了你再陪你"
- 暗示核心冲突或情感高潮
- 保留悬念，不直接揭示剧情
- 符合番茄小说风格

### 标题设计原则
1. **前半部分**：点明核心设定或场景（魔神容器、时间之眼的代价）
2. **后半部分**：情感冲击或关系张力（杀了你再陪你、黑暗吞噬）
3. **避免**：纯描述性词汇（"真相"、"升级"、"开始"、"结束"）

### 案例对比
| ❌ 错误（直白） | ✅ 正确（evocative） |
|----------------|---------------------|
| 真相大白·升级 | 魔神容器！杀了你再陪你 |
| 失明与恐慌 | 时间之眼的代价！黑暗吞噬 |
| 感知进化 | 感知进化！我能感觉到你了 |

## 开篇场景连续性检查

### 常见错误模式
- **重复上一章结尾**：第105章又写"回到营地"，而第104章已经在营地
- **时间线跳跃**：上一章结尾在A地，下一章开头又在B地，没有过渡
- **状态不一致**：上一章受伤昏迷，下一章立刻满血战斗

### 修正方法
1. **创作前必读上一章终稿**，确认结尾场景、角色位置、身体状态
2. **直接承接**：从上一章结尾的下一秒开始，不重复已发生的内容
3. **状态延续**：受伤、疲惫、情绪等状态必须延续到下一章
4. **避免**：重新描述已经完成的动作（如"回到营地"）

### 案例
**第104章结尾**：苏辰在营帐中说"我看不清了"，视力开始模糊
**第105章原错误开篇**：又写"三准圣遁光落在营地"（重复回到营地）
**修正后**：直接从营帐场景继续，苏辰视力继续恶化直至失明

## 反AI味表达检查

### 常见错误模式
- **抽象总结**："失明不是失去，是转换"
- **道理先行**："他终于明白，真正的力量来自内心"
- **概念化表达**："这是从量变到质变的飞跃"
- **作者式评论**：直接解释角色心理，而非通过动作展现

### 修正方法
1. **用具体场景代替抽象总结**：不写"失明不是失去，是转换"，写战斗中指尖感受到的混沌气息
2. **用身体反应代替心理分析**：不写"他感到恐惧"，写"手指颤抖、呼吸急促"
3. **用对话代替内心独白**：让角色通过对话表达，而非旁白解释
4. **保留不确定性**：不总结角色"明白了什么"，让读者从行动中体会

### 案例对比
**修正前（AI味）**：
```
苏辰发现：失明不是失去，是转换。他获得了新的感知能力。
```

**修正后（人味）**：
```
苏辰在战斗中意识到——看不见之后，他反而能"感觉"到以前感觉不到的东西。
不是想通了什么道理，是实战中发现的新能力。
他的指尖残留着混沌气息的触感。
```

## 系统提示频率定义

### 两种系统提示类型

**1. 系统与宿主完整对话（MINIMAL原则）**
- **定义**：系统与宿主之间有来有回的完整对话框式交流
- **频率**：≤2次/章
- **出现时机**：仅在关键节点（突破/重大奖励/危机）
- **示例**：
  ```
  【系统，这到底是怎么回事？】
  【宿主，时间之眼与你的混沌本源产生共鸣，这是进化的契机。】
  ```

**2. 系统状态提示（背景反馈）**
- **定义**：系统发出的简短状态提示，无对话交互
- **频率**：按场景类型
  - 日常修炼：5-8次/章
  - 战斗场景：8-12次/章
  - 突破/危机：10-15次/章
- **示例**：
  ```
  【叮，检测到时间法则波动，吞噬进化点+1000】
  【警告：宿主视力持续下降，预计72小时后完全失明】
  ```

### 关键区分
- **完整对话**：计入MINIMAL限制的1-2次
- **状态提示**：属于背景反馈，不计入对话次数
- **数据面板**：每3-5章展示一次，单独计算

## 风格一致性检查

### 检查流程
1. **创作前必读voice_config.json**，确认：
   - 叙事风格（第三人称限知视角）
   - 对话风格（口语化，符合人设）
   - 情感表达（克制内敛，用行动代替抒情）
   - 质量阈值（字数、省略号、系统提示等）
2. **对比前3章终稿**，确保：
   - 段落长度一致
   - 对话密度一致
   - 系统提示频率一致
   - 情感表达方式一致

### 常见不一致
- 前几章系统提示用【】，本章突然不用
- 前几章对话占比30%，本章突然60%
- 前几章省略号≤10个，本章突然30个
- 前几章情感克制，本章突然煽情

## 角色关系与CP线发展检查

### CP线发展节奏控制

**核心原则**：CP关系不能"一下子好了"，需要渐进发展和缓冲期

#### 发展阶段定义

**第1阶段：起点（暗示级）**
- 下意识关注、偶遇、多看一眼
- 关注方自己也不确定为什么关注
- 被关注方完全没察觉
- 只有行为细节，无情感宣告

**第2阶段：发展（渐进级）**
- 多次"偶遇"、逐渐意识到关注
- 开始主动靠近，但找合理借口
- 被关注方开始疑惑，但误读为其他关系

**第3阶段：察觉（疑惑级）**
- 被关注方察觉到异常，但不确定是什么
- 可能误读为"好姐妹"、"战友关心"等
- 双方开始试探

**第4阶段：确认（明朗级）**
- 双方意识到关系变化
- 但可能仍有误读或不敢确认
- 需要外部事件推动确认

#### 常见错误模式
- **发展过快**：第1章刚认识，第2章就"独处微妙氛围"
- **过度明示**：初期就有明显情感表达或身体接触
- **缺乏缓冲**：从"放下前任"直接到"关注新对象"，没有过渡

#### 修正方法
1. **起点阶段**：用"下意识"、"没意识到"、"惯性"等词
2. **行为细节**：多看一眼、站得近、呼吸同步，而非情感宣告
3. **单向性**：初期必须是一方关注，另一方完全没察觉
4. **自我不确定**：关注方自己也不确定为什么关注

#### 案例对比

**错误（发展过快）**：
```
火灵儿释然放下苏辰后，主动找到敖灵。
两人独处时，气氛微妙。
火灵儿看着敖灵，心中涌起异样情愫。
```

**正确（缓冲期起点）**：
```
火灵儿转身离去，走向营地边缘。
清晨起身，先望向苏辰营帐方向（惯性），然后移开视线。
探查时偶遇敖灵，下意识说"我发现了一些情况"。
汇报完，没有立刻离开（自己也没意识到为什么）。
```

## 钩子设计与冲突解决

### 钩子冲突识别

**常见冲突类型**：
1. **道具重复**：plot_engine钩子涉及已获取的道具（如凤凰族守护始祖之卵，但主角已获取涅槃之卵）
2. **场景冲突**：钩子场景与已有剧情矛盾（如角色在A地，钩子要求B地）
3. **关系冲突**：钩子涉及的关系与当前角色关系不符

### 钩子重新设计原则

**当plot_engine钩子与已有剧情冲突时**：
1. **必须重新设计**，不能强行使用
2. **新钩子必须服务于后续章节**（衔接plot_engine规划）
3. **可考虑方向**：
   - 配角成长线（如火灵儿"走自己的路"）
   - 新能力发现（如混沌感知的意外应用）
   - 阵营情报（如帝江残党异动）
   - 其他伏笔（如罗睺的监视印记）

### 案例：第108章钩子修正

**原钩子（冲突）**："凤凰族曾守护始祖之卵"
- 冲突点：苏辰已从凤族获取涅槃之卵，重复

**新钩子（解决）**：
- 火灵儿探查发现罗睺时间印记 + 帝江残党空间陷阱
- 服务于第109章"战略对峙"（苏辰主动出营）

## 章节衔接技巧

### 情绪转变过渡

**常见错误**：
- 上一章结尾情绪高潮，下一章开头直接跳到新场景
- 缺乏情绪缓冲和过渡
- 配角的情感转变没有交代

**修正方法**：
1. **新增【序幕】**：专门处理上一章结尾的延续
2. **时间跳跃交代**：用内心独白或行为暗示中间发生了什么
3. **配角视角**：用配角行动展现情绪转变（如火灵儿转身离去后的独处）

### 案例：第107-108章衔接

**第107章结尾**：
- 苏辰和敖灵在营帐中，"我们一起"
- 火灵儿帐外听到，释然离去

**第108章【序幕】**：
- 火灵儿转身离去，嘴角微笑眼眶发热
- 走向营地边缘，不想见人（走自己的路）
- 时间跳跃：深夜→黎明
- 清晨起身，惯性望向苏辰营帐，然后移开视线（克制）
- 决定探查营地周边（引出正戏）

### 关键检查点
- [ ] 上一章结尾的角色位置是否延续
- [ ] 情绪状态是否有过渡
- [ ] 配角的行动是否有交代
- [ ] 时间跳跃是否有暗示

## 角色关系调整工作流

### 何时需要调整角色关系

**触发条件**：
1. 用户明确要求新的角色关系定位
2. 创作中发现现有关系与剧情冲突
3. 角色发展自然偏离初始设定

### 调整步骤

**步骤1：明确新定位**
- 记录每个角色的新关系定位
- 标注关系类型（暗恋/好基友/CP暗示等）
- 确定关系级别（明示/暗示/单向等）

**步骤2：更新角色卡**
- 修改 character_cards.json
- 添加关系字段（如 relationship_blind_spots、emotional_signals）
- 更新 relationship_network.json

**步骤3：设计体现方式**
- 暗恋：关心被误解、信号被无视
- 好基友：调侃、竞争、但一方不懂
- CP暗示：偶遇、多看一眼、站得近

**步骤4：验证一致性**
- 检查所有角色的关系定位是否冲突
- 确保阵营立场符合 faction_config.json
- 验证人设一致性（感情白痴不能突然开窍）

### 案例：第108章角色关系调整

**新定位**：
- 苏辰：感情白痴（完全不开窍）
- 敖灵：暗恋苏辰（信号被无视）
- 火灵儿×敖灵：CP暗示级（敖灵完全没察觉）
- 麒天×苏辰：好基友（苏辰不懂）

**角色卡更新**：
- 苏辰：添加 emotional_intelligence: "极低"、relationship_blind_spots
- 敖灵：添加 emotional_expression、emotional_blind_spots
- 火灵儿：添加 emotional_arc、cp_development
- 麒天：添加 emotional_signals、cp_development

## 从用户编辑中学习（第100-107章）

### 五星评价维度

#### 1. 风格统一性 ⭐⭐⭐⭐⭐
**核心要点**：
- 简洁有力，避免堆砌辞藻
- 第三人称限知视角（主角苏辰）
- 克制内敛，用行动代替抒情
- 删除冗余形容词，保留必要修饰

**学习案例**：
- ❌ "手指无意识地摩挲着身下的石床，粗糙的纹理在指腹下反复摩擦，带来一种近乎麻木的触感"
- ✅ "手指摩挲着石床，粗糙的纹理在指腹下摩擦"

**应用检查**：
- [ ] 每句不超过30字
- [ ] 形容词≤2个/句
- [ ] 避免"一种...的感觉"句式

#### 2. AI味去除 ⭐⭐⭐⭐⭐
**核心要点**：
- 删除抽象情绪词（"恐惧如潮水般涌来"）
- 用行动代替抒情（"手指颤抖"代替"感到恐惧"）
- 避免排比句式煽情
- 禁止主题先行总结

**学习案例**：
- ❌ "他终于明白，失明不是失去，是转换"
- ✅ "指尖残留着混沌气息的触感"

**AI味词汇黑名单**：
- "终于明白"、"恍然大悟"、"深刻体会"
- "不是...而是..."总结句式
- "这一刻，他懂得了..."
- "这就是...的真谛"

**应用检查**：
- [ ] 抽象情绪词≤5次/章
- [ ] 排比句式=0
- [ ] 主题先行总结=0

#### 3. 人设准确性 ⭐⭐⭐⭐⭐
**核心要点**：
- 苏辰：功能性思维、理性分析、禁止感性独白
- 敖灵：傲娇、主权宣示、嘴上嫌弃行动关心
- 对话带关系态度，不只传信息
- 阵营立场一致（麒麟族不谈儿女情长）

**学习案例**：
- ❌ 苏辰："无论前方有什么，我都不会退缩"
- ✅ 苏辰："计算一下，胜率三成，但值得一试"

**角色对话检查表**：
- [ ] 苏辰台词带利益计算
- [ ] 敖灵台词带债务提醒或主权宣示
- [ ] 禁止苏辰说感性台词（"我会保护你"）
- [ ] 禁止敖灵过于温柔主动

#### 4. 节奏紧凑度 ⭐⭐⭐⭐⭐
**核心要点**：
- 删除与上一章重复的场景切入
- 直接进入核心冲突，减少铺垫
- 对话保留核心冲突，删除AI味铺垫
- 战斗场景保持爽点密度

**学习案例**：
- ❌ 第105章原开篇："三准圣遁光落在营地..."（与第104章重复）
- ✅ 修正后：直接从营帐场景开始

**节奏检查**：
- [ ] 无重复场景切入
- [ ] 首段进入核心冲突或状态
- [ ] 对话无冗余铺垫
- [ ] 战斗场景≥500字

### 用户编辑最佳实践

#### 场景切入
**原则**：承接上一章结尾，不重复已发生内容
- 第104章结尾在营帐 → 第105章直接从营帐开始
- 删除"回到营地"、"抵达营地"等重复描述

#### 情感表达
**原则**：用行动和对话代替内心独白
- ❌ "他感到前所未有的孤独"
- ✅ "他坐在黑暗中，握着一个他看不见的人的手"

#### 对话节奏
**原则**：保留核心冲突，删除铺垫性对话
- ❌ "你知道吗，我一直想告诉你..."（铺垫）
- ✅ "系统92%魔神关联度。"（直接）

#### 战斗描写
**原则**：保持爽点密度，不压缩过度
- 保留具体动作："右手成爪，直接穿透了对方的防御"
- 保留感官细节："金色的血液飞溅"
- 保留结果反馈："骨骼碎裂的声音"
