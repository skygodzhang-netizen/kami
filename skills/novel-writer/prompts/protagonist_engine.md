# 任务：生成主角引擎（Protagonist Engine）

设计一个**让读者代入、想看他赢**的主角。

## 输入
- **世界观爽点**：{{world_hooks}}
- **核心爽感**：{{core_pleasure}}

## 输出

### 基础设定
- **姓名**：好记，有辨识度
- **初始身份**：低起点（方便升级），但有特殊之处
- **核心目标**：明确，可量化，读者能理解
  - 示例："三年内打败XX"、"找到失踪的妹妹"、"成为最强"

### 性格标签（3-4个，有反差）
- 示例："表面冷静内心吐槽"、"看似懦弱实则狠辣"、"热血但记仇"
- **关键**：必须有让读者喜欢的点（正义感/幽默感/坚韧）

### 金手指/优势（核心）
- **是什么**：具体能力
- **怎么来的**：有故事性
- **限制**：必须有，增加张力
- **升级感**：如何让读者感受到"变强了"

### 初始状态（让读者同情）
- **困境**：被欺压/被误解/资源匮乏/身负诅咒
- **情绪状态**：压抑但不服输/迷茫但有执念
- **让读者想**："快让他翻身吧！"

### 成长弧光（非等级，是性格）
- **初期**：谨慎/隐忍/单打独斗
- **中期**：主动/有盟友/敢于冒险
- **后期**：领袖/有担当/但保留核心特质

### 说话方式（区分度）
- **内心独白**：吐槽多？冷静分析？热血自我激励？
- **对外说话**：直接？ sarcastic？礼貌但疏离？
- **情绪高点**：口头禅或特定反应（非强制，自然出现）

### 让读者爽的特质
- [ ] **有仇必报**：不圣母，打脸及时
- [ ] **聪明**：不是无脑莽，有策略
- [ ] **有底线**：不真反派，读者能共情
- [ ] **成长感**：明显变强，可视化

## 下游引用
- `protagonist_drive`：核心目标+性格
- `protagonist_voice`：说话方式
- `protagonist_growth`：成长节点
