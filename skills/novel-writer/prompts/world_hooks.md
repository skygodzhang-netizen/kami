# 任务：生成世界观爽点预埋（World Hooks）

设计一个**为爽文服务**的世界观，而非单纯背景。

## 核心输入
- **题材**：{{genre}}（决定世界观**结构**与爽点类型）
- **核心爽感**：{{core_pleasure}}（升级/智斗/种田/情感/日常/搞笑/其他，可配置）

> 叙事**口吻**（日常、搞笑、擦边边界）由 `voice_config` / `author_profile.json` 的 `author_signature` 控制，不在本步骤定义。

## 输出：爽点预埋系统

### 1. 金手指/优势体系（主角外挂）
- **来源**：意外获得/前世记忆/特殊体质/系统
- **表现形式**：可视化面板/隐藏能力/知识差
- **限制条件**：必须有，否则无敌无聊（能量/代价/冷却/副作用）
- **升级路径**：明确的成长阶梯，让读者有期待

### 2. 冲突放大器（为什么一直有架打）
- **表层冲突**：资源争夺/门派斗争/正邪对立
- **深层冲突**：身份矛盾（主角双重身份）/ 理念冲突 / 生存压力
- **冲突升级机制**：主角变强→敌人变强→ stakes 提高

### 3. 升级可视化体系（战力清晰）
- **等级名称**：每级有明确名称和特征
- **突破爽点**：每次突破有明显外在表现（天地异象/全场震惊）
- **战力对比**：能清晰展示主角"越级挑战"的震撼感

### 4. 关键地图/势力（舞台）
设计3-5个关键势力，每个都有：
- **与主角关系**：敌人/潜在盟友/中立可利用
- **核心资源**：主角需要的某样东西
- **冲突点**：必然与主角发生摩擦的原因

### 5. 爽点场景预埋（经典桥段准备）
在世界观中预埋以下经典爽点场景的可能性：
- [ ] **拍卖会装逼**：有货币体系/稀有物品/嚣张对手
- [ ] **宗门大比**：有公开比试机制/等级差距可视化
- [ ] **秘境探险**：有未知地图/宝物/危险/时间限制
- [ ] **身份揭露**：有隐藏身份/误会/反转空间
- [ ] **生死危机**：有 deadline / 强敌 / 绝境反转机制

## 输出格式
**禁止大段背景描述**，用 bullet points 列出：
- 金手指：...
- 升级体系：...
- 主要冲突源：...
- 关键势力（仅关系+资源+冲突点）：...
- 预埋爽点场景：...
