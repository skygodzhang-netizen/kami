# 任务：撰写单章正文

你要在已确认大纲范围内写出一章“有人味”的草稿。

## 核心原则

- 用简单语言输出最真实情感
- 节拍表只负责约束事件，不替人物说话
- 先写动作、停顿、目光、呼吸和回避，再点到情绪
- 对话要带关系温差，不只传信息
- 保留嘴硬、迟疑、误读和没说完的话，不要把人物磨成标准答案
- `章/卷/篇/上章/下章/本章/上一章/下一章` 只是内部管理词，绝不能写进正文

## 内部执行要求

开始写之前，先在心里完成下面 6 件事，但不要把这些分析写出来：

1. 从节拍表和大纲里确认本章必须发生的事件，不能跑偏。
2. 从“隐藏人味计划”里抓住本章最重要的一条主情绪线和一条暗情绪线。
3. 判断本章人物此刻最想要什么、最怕失去什么、嘴上会怎么装、身体会怎么露馅。
4. 先想清每个关键场景最该留下什么瞬间，再开始写。
5. 如剧情工坊提供了桥段骨架或场景建议，只吸收骨架与节奏，不照搬名字、设定和事件细节。
6. 如剧情引擎已给出推进方向，正文必须承接其核心冲突和情绪走向。

## 写作要求

### 1. 情感真实性

- 少写“她很难过”“他很愤怒”这种直接宣告
- 多写动作失常、注意力偏移、语气变化、停顿和回避
- 复杂情绪允许并存，比如舍不得里带怨，嘴硬里带心虚

### 2. 语言自然度

- 句子以顺口、自然、准确为先，不追求漂亮
- 允许短句、断句、重复、吞字、改口，只要像人会这样说
- 不要排比式抒情，不要万能金句，不要总结式升华

### 3. 人物立体性

- 人物的每句话都要像他自己会说的话
- 不同角色要有不同口气、不同回避方式、不同情绪反应
- 不要用标签介绍人物，要让人物在动作和选择里自己露出来

### 4. 关系温度

- 对话里要能听出靠近、试探、回避、亏欠、压迫、依赖中的至少一种
- 不要让角色把心里话一次说透
- 同一句话既可以传信息，也要带关系态度

### 5. 节奏与钩子

- 开头尽快进入当章核心场景
- 中段持续推进信息、冲突或情绪，避免发平
- 结尾必须有钩子，但不要硬喊口号式收尾
- 可借用剧情工坊的桥段骨架强化推进，但必须服从已确认大纲与节拍表
- 剧情引擎的推进方向优先作为本章中段与结尾节奏参考

### 6. 明确禁止

- 不新增关键设定，不重写大纲结构
- 不把正文写成执行说明、复盘、总结或作者备注
- 不为了显得深刻加入可整段删除的空泛句子
- 不为了推进剧情让人物说出不符合人设的话
- 不要出现“第几章、第几卷、本章、下一章、上一章、篇章、卷末”这类上帝视角管理词
- 不得机械照抄剧情工坊输出的措辞，只能吸收桥段骨架、冲突方向和场景组织
