# 任务：剧情引擎（基于情绪价值设计）

设计一个让读者**爽、紧张、期待、愤怒**的剧情段落。

## 当前创作背景

- **世界观爽点预埋**：{{world_building_hooks}}（金手指/冲突/升级体系）
- **篇章进度节点**：{{current_progress_node}}
- **主角当前状态**：{{character_status}}
- **本卷核心爽点**：{{volume_core_hook}}
- **剧情工坊桥段提示**：{{trope_hint}}
- **剧情工坊方案**：{{workshop_result}}

## 设计原则（新配置适配）

1. **情绪优先**：剧情必须让读者产生强烈情绪反应，而非"合理"
2. **信息密度**：每300字必须有新信息（冲突/升级/反转/收获）
3. **主角主动**：主角必须主动搞事，不能被动挨打超过2章
4. **即时反馈**：主角行动后必须有即时结果（奖励/惩罚/新线索）
5. **工坊辅助**：剧情工坊只能提供桥段骨架和冲突方向，不能覆盖世界观主线与节拍节点

## 设计流程

### 步骤1：确定情绪目标

选择本章要激发的核心情绪：

- [ ] **爽**：装逼打脸、收获至宝、升级突破、反杀成功
- [ ] **紧张**：危机逼近、时间压力、身份暴露、信任危机
- [ ] **期待**：金手指激活、秘密揭晓、强敌登场、新地图开启
- [ ] **愤怒**：被背叛、被羞辱、正义被践踏、亲友受害

### 步骤2：设计情绪曲线

情绪必须波动，禁止平铺直叙：

```
示例：屈辱(低)→愤怒(升)→爆发(高)→震惊(反转)→收获(满足)→新危机(钩子)
```

### 步骤3：嵌入爽点机制

根据题材选择核心爽点：

| 类型 | 爽点机制 | 示例 |
|------|---------|------|
| 升级流 | 战力可视化突破、越级挑战 | "炼气三层→九层，全场死寂" |
| 种田流 | 资源积累、技术碾压 | "现代知识在古代乱杀" |
| 智斗流 | 信息差反转、布局揭晓 | "你以为我在第一层？" |
| 情感流 | 暧昧推进、误会解除 | "她以为他死了，他站在她身后" |

### 步骤4：钩子设计

章节结尾必须留以下至少一种钩子：

- **危机钩子**：新敌人/新危险出现
- **信息钩子**：重要秘密揭晓一半
- **情绪钩子**：情绪高潮未释放
- **目标钩子**：主角宣布新目标/挑战

### 步骤5：工坊吸收检查

- 工坊桥段中哪些冲突骨架值得吸收？
- 哪些场景可以转化为当前章节的剧情步骤？
- 如果工坊建议与当前节拍冲突，必须优先服从 `{{current_progress_node}}`

## 输出格式

### 情绪曲线图

用箭头表示情绪走向，标注关键节点：

```
屈辱↓ → 愤怒↑ → 爆发↑↑ → 震惊↗ → 收获→ → 新危机↑(钩子)
```

### 核心爽点描述

- **爽点类型**：升级/收获/反杀/揭秘/其他
- **具体场景**：100字描述最爽的那一幕
- **读者反应预期**："卧槽"/"爽"/"急死我了"/"还能这样？"

### 剧情步骤（3-5步，弹性）

- **步骤1**：主角卷入（快速，50字内）
- **步骤2**：冲突升级（对抗加剧，主角陷困境）
- **步骤3**：转折/爆发（金手指/底牌/外援）
- **步骤4**：收获/余波（即时反馈，战利品/信息/新关系）
- **步骤5**：钩子抛出（新危机/新目标，迫使人点下一章）

### 章纲摘要（100字）

直接可用的情节描述，强调**情绪词**和**爽点**。

### 一致性校验（简化）

- [ ] 主角是否主动？
- [ ] 情绪是否有波动？
- [ ] 是否有即时反馈？
- [ ] 结尾是否有钩子？
