# 任务：设计卷情绪弧（Volume Arc）

规划一卷的**情绪起伏**和**追更钩子**，而非单纯事件。

## 输入信息
- **世界观爽点**：{{world_hooks}}
- **预计总字数**：{{target_word_count}}
- **单章弹性字数**：2000-4000字

## 输出要求

### 卷主题（情绪关键词）
用3-5个情绪词概括本卷：
- 示例："屈辱→崛起→震惊→复仇→新威胁"
- 示例："悬疑→恐惧→揭秘→反转→更大阴谋"

### 钩子链设计（每章结尾留什么）
规划本卷5-8个关键钩子，分布在章节结尾：

| 章号区间 | 钩子类型 | 具体内容 | 读者预期反应 |
|----------|---------|---------|-------------|
| 1-3章 | 危机钩子 | 主角被陷害， deadline 3天 | "他怎么破局？" |
| 8-10章 | 升级钩子 | 金手指激活，能力暴涨 | "终于要爽了！" |
| 15-18章 | 反转钩子 | 反派是盟友/盟友是反派 | "卧槽，被骗了！" |
| ... | ... | ... | ... |

### 情绪曲线图
用简单折线图表示整卷情绪走向：

```
章1-5: 压抑↓
章6-10: 反弹↑（第一次爽）
章11-15: 平台→（积累）
章16-20: 爆发↑↑（卷高潮）
章20结尾: 新危机↑（卷钩子）
```

### 核心爽点分布
列出本卷3-5个必写的爽点场景：
1. **爽点1（第X章）**：主角当众打脸反派，战力可视化
2. **爽点2（第X章）**：收获关键道具/技能，升级感
3. **爽点3（第X章）**：揭秘重要秘密，信息差反转
...

### 主角成长线（非等级，是状态）
- **卷初状态**：被欺压/迷茫/弱鸡
- **卷中转折**：获得X/领悟X/决定X
- **卷末状态**：崛起/复仇成功/但失去X/面临更大危机

### 卷尾大钩子（必须）
用1句话描述卷末悬念，让读者必须看下一卷：
- 示例："他以为赢了，但真正的敌人刚刚睁开眼睛。"
- 示例："她终于找到了他，但他已经不认识她了。"
