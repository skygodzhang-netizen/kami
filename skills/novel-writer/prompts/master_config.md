# 网文实战配置 - 总控文档

本文档定义整套Prompt系统的核心原则，所有子Prompt必须遵循。

## 核心哲学（不可违背）

### 0. 题材 vs 作者签名
- **题材（genre）**：per-project，决定世界观结构、冲突类型、节奏模板（修仙/校园/悬疑等）
- **作者签名（author_signature）**：per-author（`config/author_profile.json`），决定日常感、幽默密度、擦边边界
- **冲突时签名优先**：不得因题材是「修仙/爽文」就覆盖作者的日常搞笑口吻；结构按题材，叙事口吻服从 `voice_config.author_signature`

### 1. 情绪 > 逻辑 > 文笔
- 优先让读者产生强烈情绪（爽/紧张/期待/愤怒）
- 逻辑自洽即可，不追求严密
- 文笔服务于情绪，不追求精致

### 2. 钩子 > 结构 > 规则
- 每章必须有钩子（结尾悬念）
- 结构服务于情绪曲线，不强制起承转合
- 规则是参考，可打破，但底线不可碰

### 3. 人味 > 精致 > 量化
- 允许口语化、重复、不完美
- 读起来像人在讲故事
- 禁止机械量化指标（强制字数/段落/感官数）

## 绝对底线（禁止触碰）

1. **连续3章无实质推进**
2. **主角被动挨打超过2章**
3. **同一信息重复解释超过2次**
4. **重要设定无铺垫突然抛出**
5. **章节结尾总结复盘（必须留钩子）**

## 弹性区间（允许自由发挥）

| 项目 | 原配置（死） | 新配置（活） |
|------|-------------|-------------|
| 单章字数 | 2600-4200强制 | 2000-5000弹性 |
| 段落字数 | 12-150强制 | 20-200自然 |
| 对话比例 | 参考 20-40%（对话推进章 45-60%） | 不为凑比例加废话 |
| 心理描写 | 60%深度分析 | 50%直接吐槽 |
| 节奏模式 | 4种强制切换 | 情绪自然流动 |
| 章节结构 | 起承转合固定 | 钩子驱动弹性 |

## 情绪曲线标准模板

每章必须有的情绪波动：
```
压抑/平静 → 冲突/紧张 → 爆发/高潮 → 余波/收获 → 钩子/新危机
↓           ↓           ↓           ↓           ↓
0-20%      20-60%       60-80%      80-95%      95-100%
```
禁止平铺直叙，禁止全程压抑无释放，禁止全程爽无危机。

## 爽点类型速查

| 类型 | 核心机制 | 情绪目标 |
|------|---------|---------|
| 升级流 | 战力可视化突破 | 爽+期待 |
| 种田流 | 资源积累技术碾压 | 满足+爽 |
| 智斗流 | 信息差反转布局 | 震惊+爽 |
| 情感流 | 暧昧推进误会解除 | 甜蜜+揪心 |
| 悬疑流 | 秘密揭晓真相浮现 | 紧张+释然 |

## 钩子类型速查

- **危机钩子**：新敌人/新危险/ deadline
- **信息钩子**：秘密揭晓一半/身份暴露风险
- **情绪钩子**：情绪高潮未释放/重大决定 pending
- **目标钩子**：新目标宣布/挑战发起/誓言立下

## 使用流程

1. **world_hooks** → 预埋爽点（结构按题材）
2. **voice_config** → 确定声音（口吻服从 author_profile）
3. **volume_arc** → 规划情绪弧
4. **chapter_beats** → 拆解节拍
5. **plot_engine**（可选）→ 复杂剧情设计
6. **chapter_hook** → 单章设计
7. **chapter_write** → 撰写正文

> `protagonist_engine.md`、`relationship_analyze.md` 为**参考 Prompt，未接线 action**，勿作为主链步骤。

## 输出统一要求

- **禁止JSON**（除必要的数据传递外）
- **禁止英文标签/小标题**
- **禁止量化指标堆砌**
- **强制自然语言描述**
- **强制情绪关键词**
- **强制钩子设计**

**记住：让读者爽，让读者急，让读者停不下来。**
