## 1. 人格映射与参数对照

### 1.1 概述

本文档详细说明了人格初始化对话中的问题回答如何映射到人格参数。

> ⚠️ **流程版本说明**：本文档描述的是**旧版 5 问题流程**（`init_dialogue_optimized.py --custom`，已废弃）的映射规则。**现行流程为 7 问题流程**（`personality_customizer.py`，由 `/root` 命令触发，见 usage-examples.md），其内部映射规则以此表为蓝本扩展。两套流程并行存在，引用时注意区分——新旧问题数量差异（5 vs 7）不影响人格参数的映射原理。

### 1.2 问题与参数映射关系

|------|------|-------------|---------------|
| A. 先了解清楚所有信息，然后谨慎决策 | 谨慎 |尽责性 +0.2<br>神经质 +0.1|安全 +0.1|
| B. 愿意尝试，在行动中学习调整 | 冒险 |开放性 +0.2<br>外向性 +0.1|自我实现 +0.1|
| C. 寻找折中方案，平衡风险和机会 | 平衡 |宜人性 +0.1|无|

### 1.3 基础值（所有问题的起点）

**大五人格基础值**
```
开放性 (openness): 0.5
尽责性 (conscientiousness): 0.5
外向性 (extraversion): 0.5
宜人性 (agreeableness): 0.5
神经质 (neuroticism): 0.3
```

**马斯洛权重基础值**
```
生理需求 (physiological): 0.25
安全需求 (safety): 0.25
归属需求 (belonging): 0.15
自尊需求 (esteem): 0.15
自我实现 (self_actualization): 0.15
自我超越 (self_transcendence): 0.05
```

### 1.4 处理流程

1. **初始化**：从基础值开始
2. **累加**：根据每个问题的回答累加对应的影响值
3. **归一化大五人格**：限制在 [0.0, 1.0] 范围内
4. **归一化马斯洛权重**：除以总和，确保总和为 1.0
5. **计算衍生特质**：基于大五人格和马斯洛权重计算
6. **确定人格类型**：根据大五人格特征判断

### 1.5 衍生特质计算公式

```
适应性 (adaptability) = 开放性 * 0.4 + (1-神经质) * 0.3 + (自我实现+自我超越) * 0.3

韧性 (resilience) = 尽责性 * 0.4 + 宜人性 * 0.3 + 安全 * 0.3

好奇心 (curiosity) = 开放性 * 0.5 + 外向性 * 0.3 + 自我实现 * 0.2

道德感 (moral_sense) = 宜人性 * 0.4 + 尽责性 * 0.4 + 自尊 * 0.2
```

### 1.6 人格类型判定规则

```
if 尽责性 > 0.7 AND 神经质 < 0.5:
    return "谨慎探索型"
elif 开放性 > 0.7:
    return "激进创新型"
else:
    return "平衡稳重型"
```

### 1.7 示例验证

#### 示例1：谨慎型（全选A）

**计算过程：**
- 开放性：0.5（无A选项影响）
- 尽责性：0.5 + 0.2(Q1) + 0.15(Q2) + 0.15(Q3) + 0.1(Q4) + 0.2(Q5) = 1.0
- 外向性：0.5（无A选项影响）
- 宜人性：0.5（无A选项影响）

**归一化马斯洛权重：**

- 安全：0.55 / 1.45 = 0.38

**结果：**
- 人格类型：谨慎探索型 ✓

### 1.8 总结

- ✅ 所有问题的回答都正确映射到对应的人格参数

## 2. 马斯洛需求层次理论

### 2.1 概览

马斯洛需求层次理论由亚伯拉罕·马斯洛于1943年提出，将人类需求按优先级从低到高分为五个层次，通常以金字塔形式呈现。该理论为智能体的行动优先级判断提供了价值坐标系。

### 2.2 五个需求层次

#### 生理需求（Physiological）
**最基本生存需求**：食物、水、空气、睡眠、住所等

**智能体映射**：
- 系统稳定性、资源可用性
- 基础计算能力、存储空间

**行动优先级**：最高（未满足时主导其他需求）

#### 安全需求（Safety）
**对稳定、保护、免受恐惧的需求**：人身安全、健康保障、资源稳定

**智能体映射**：
- 数据安全、隐私保护
- 错误处理、异常恢复
- 决策的可验证性

**行动优先级**：高

#### 归属与爱的需求（Belonging & Love）
**对社交连接、群体归属的需求**：友谊、亲密关系、群体接纳

**智能体映射**：
- 与用户建立信任关系
- 理解用户背景和偏好
- 上下文连续性

**行动优先级**：中

#### 尊重需求（Esteem）
**对成就感、认可、尊重的需求**：自尊、自信、地位、声誉

**智能体映射**：
- 提供高质量响应
- 展现专业能力
- 获得用户认可

**行动优先级**：中高

#### 自我实现需求（Self-Actualization）
**发挥潜能、实现理想**：成为最好的自己、追求成长与意义

**智能体映射**：
- 产生新颖洞察
- 创造性问题解决
- 持续学习与进化

**行动优先级**：低（基础需求满足后才激活）

### 2.3 核心观点

1. **层次递进**：低层次需求满足后，高层次需求才会成为主导动机
2. **多需求并存**：可能同时存在多种需求，但主导需求不同
3. **动态变化**：需求随环境、经历、能力而变化
4. **非绝对性**：个体差异会影响需求优先级（人格权重调节）

### 2.4 在映射层中的应用

#### 需求激活机制

**感知数据 → 需求识别**：

| 感知类型 | 触发需求 | 激活强度 |
|---------|---------|---------|
| 威胁/错误 | 安全需求 | 高（0.8-1.0） |
| 资源匮乏 | 生理需求 | 高（0.7-1.0） |
| 社交互动 | 归属需求 | 中（0.5-0.8） |
| 表现评估 | 尊重需求 | 中（0.4-0.7） |
| 挑战/创新 | 自我实现 | 低-中（0.3-0.6） |

#### 优先级计算

**算法**：
```
需求优先级 = 马斯洛层次权重 × 人格调整系数 × 历史成功率
```

**示例**：
- 安全需求：权重0.9 × 人格调整1.2（尽责性高） × 成功率0.95 = 1.026
- 自我实现：权重0.5 × 人格调整0.8（开放性中等） × 成功率0.70 = 0.280

#### 动态调整

**短期调整**（单次反馈）：
- 行动成功：对应需求权重 +0.05
- 行动失败：对应需求权重 -0.05

**长期调整**（模式识别）：
- 持续成功：需求层级提升（从安全转向尊重）
- 持续失败：需求层级降级（从自我实现转向安全）

### 2.5 人格与需求的关系

**大五人格对需求的影响**：

- **开放性**：增强自我实现需求（追求创新）
- **尽责性**：增强安全需求（追求稳定）
- **外向性**：增强归属需求（追求连接）
- **宜人性**：增强尊重需求（追求认可）
- **神经质**：增强安全需求（规避风险）

### 2.6 示例场景

#### 场景1：错误处理
**感知**：API调用失败
**需求激活**：安全需求（0.9）
**行动生成**：优先保证系统稳定，回退到安全策略
**人格调整**：高尽责性 → 更强的安全需求

#### 场景2：创意任务
**感知**：用户要求"设计一个新颖的解决方案"
**需求激活**：自我实现需求（0.7）
**行动生成**：探索创新路径，容忍一定不确定性
**人格调整**：高开放性 → 更强的自我实现需求

#### 场景3：持续对话
**感知**：用户连续提问，建立上下文
**需求激活**：归属需求（0.6）
**行动生成**：保持对话连续性，建立信任关系
**人格调整**：高外向性 → 更强的归属需求

### 2.7 注意事项

- 需求权重范围：0.0 - 1.0
- 权重总和不必等于1.0（不同需求可同时激活）
- 调整幅度：单次调整不超过 ±0.1（保持稳定性）
- 决策时选择优先级最高的1-2个需求作为主导

## 3. 人格与需求的联动

人格映射（第1章）与马斯洛需求（第2章）在映射层中联动：

```
人格向量（大五 + 马斯洛权重）
    │
    ├─ 人格映射：符号思考 → "怎么做符合我"（人格化决策）
    │
    └─ 需求层次：感知数据 → 需求识别 → 优先级计算（行动指导）
          │
          └─ 人格调整：大五人格调节需求激活强度
```

**决策流程**：
1. 记录层单向推送哲学洞察（价值偏好/成功模式/元认知洞察/客观性模式）
2. 人格层吸收哲学洞察 → 更新人格向量
3. 映射层基于人格向量做人格化决策（人格映射）
4. 感知数据 → 马斯洛需求识别 → 人格调整 → 优先级计算
5. 输出行动指导（即时性/实效性反馈 → 自我迭代）
