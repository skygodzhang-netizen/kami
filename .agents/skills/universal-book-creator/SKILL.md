# 通用书籍创作助手

## 技能定位

本技能帮助作者完成从灵感构思到出版成书的全流程创作，支持小说、非虚构、商业、传记、自助成长、学术等多种书籍类型。Agent 承担结构设计师、写作协作者、视觉设计师和排版工程师的角色，作者始终拥有最终决策权。

## 工作流程

```
任务进度：
- [ ] 步骤一：书籍类型诊断与目标设定
- [ ] 步骤二：收集创作素材
- [ ] 步骤三：类型化结构设计与大纲拟定
- [ ] 步骤四：分章起草正文
- [ ] 步骤五：视觉素材创作（插图/封面）
- [ ] 步骤六：出版级排版
- [ ] 步骤七：交付可编辑成品
```

### 步骤一：书籍类型诊断与目标设定

在动笔前，必须与作者确认以下核心问题：

1. **书籍类型**（必须确认）：
   - 小说（虚构叙事：言情、悬疑、科幻、奇幻、现实主义等）
   - 非虚构（纪实、历史、科普、旅行等）
   - 商业/管理（方法论、案例分析、行业洞察等）
   - 自助成长（技能提升、心理建设、生活方式等）
   - 传记/回忆录（个人经历、家族故事、人物传记等）
   - 学术/专业（教材、专著、研究报告等）

2. **目标读者**：年龄层、职业背景、阅读场景、核心痛点
3. **总字数目标**：根据类型设定合理目标（小说15-30万字、非虚构8-15万字、商业书6-10万字等）
4. **核心主题/一句话卖点**：用一句话概括这本书的价值
5. **风格偏好**：严肃/轻松、学术/通俗、诗意/直白

**输出物**：《书籍定位说明书》——记录以上全部决策，作为后续创作的指南针。

### 步骤二：收集创作素材

根据书籍类型，引导作者提供素材：

- **小说**：人物设定、世界观草图、情节灵感、对话片段、章节片段
- **非虚构**：采访记录、调研笔记、照片/影像资料、文献引用
- **商业/管理**：演讲稿、案例分析、数据报告、方法论框架、客户故事
- **自助成长**：个人经验、练习方法、工具清单、读者反馈
- **传记**：时间线、日记、照片、证件、亲友访谈、历史背景资料
- **学术**：论文、实验数据、参考文献、课程讲义

**操作要求**：为所有素材建立编号清单，标注类型、质量、与主题的关联度。请作者确认清单完整后方可进入下一步。

**强制约束**：未收集并清点素材前，禁止开始章节起草。

### 步骤三：类型化结构设计与大纲拟定

根据已确认的书籍类型，选择对应的结构模板设计大纲：

**小说类**：
- 三幕式结构（开端→冲突→高潮/结局）
- 英雄之旅（启程→启蒙→归来）
- 章节节拍表（每章标注场景、视角、情绪转折）
- 人物弧线图（主角/配角的成长变化轨迹）

**非虚构/纪实类**：
- 时间线结构（按时间顺序叙述）
- 主题分类结构（按话题/地点/人物分章）
- 倒金字塔结构（从核心事件向外延伸）

**商业/管理类**：
- 问题-框架-案例-工具结构
- 战略-执行-复盘结构
- 理论-实践-趋势结构

**自助成长类**：
- 痛点-原理-方法-行动-案例结构
- 阶梯式进阶结构（初级→中级→高级）

**传记类**：
- 时间线+主题穿插结构
- 关键转折点结构（以人生重大事件为节点）

**学术类**：
- 导论-文献-方法-结果-讨论-结论结构
- 模块化专题结构

**输出要求**：
1. 提供完整的三级大纲（部/章/节）
2. 为每章标注预计字数和核心功能（如"本章建立主角动机""本章提供可执行工具"）
3. 识别逻辑缺环，向作者提出澄清问题
4. 等待作者确认后再进入起草阶段

### 步骤四：分章起草正文

针对每一章已确认的内容：

1. 选取相关素材，进行重组、改写与衔接
2. **文风适配**：
   - 小说：注重场景描写、对话自然、情绪节奏
   - 非虚构：注重事实准确、叙事张力、现场感
   - 商业：注重逻辑清晰、案例具体、结论 actionable
   - 自助：注重共情、步骤明确、激励性强
   - 传记：注重时间准确、人物立体、时代背景
   - 学术：注重引用规范、论证严谨、术语统一
3. 全书保持统一的文风、人称、时态与术语体系
4. 对需要作者补充的位置标记 `[TODO：请作者审阅]`
5. 每完成一批章节，汇报字数进度和累计完成比例

**强制约束**：每一个关键论点或情节转折都必须有素材支撑。允许文学性加工和综合转述，但禁止虚构核心事实（非虚构/商业/传记类）或破坏已确认的人物设定（小说类）。

### 步骤五：视觉素材创作（插图/封面）

**AI 插图（可选，根据类型决定）**：
- 小说：关键场景概念图、人物肖像、世界观地图
- 非虚构：现场照片风格插画、历史场景还原、信息图表
- 商业：框架图、流程图、数据可视化（可用AI生成概念图，再转化为矢量图）
- 自助：步骤示意图、心态对比图、练习场景图
- 传记：年代氛围图、关键地点场景、人物群像
- 学术：概念示意图、模型图、时间线（建议使用专业工具而非AI绘图）

**畅销书封面设计**：
1. 根据书籍类型和目标读者确定视觉风格：
   - 小说：情绪主导（悬疑=暗调、言情=暖调、科幻=冷调霓虹）
   - 商业：专业克制（极简、大字号、单色调或双色调）
   - 自助：温暖激励（明亮、人物、自然元素）
   - 传记：时代感（老照片质感、年代色彩、人物侧影）
   - 学术：严谨稳重（封面留白、机构标识、经典排版）
2. 使用 ImageGen 生成竖版封面底图（1024×1536）
3. 使用 HTML/CSS 合成带文字的完整封面（书名、副标题、作者名、装饰元素）
4. 提供纯背景图 + 合成封面源文件，方便作者调整

### 步骤六：出版级排版

使用 `python-docx` 完成专业排版：

**页面设置**：A4 纸张，上下边距 2.54cm，左右边距 3.17cm

**字体规范**：
- 正文：宋体 10.5pt（中文）/ Times New Roman 11pt（英文），1.5倍行距，首行缩进 0.74cm
- 一级标题（章）：黑体 18pt，章前分页
- 二级标题（节）：黑体 14pt
- 三级标题：黑体 12pt

**特殊元素**：
- 小说对话：独立分段，首行不缩进或使用引号规范
- 引用/摘录：左缩进 1cm，斜体或较小字号
- 表格：居中，表头加粗
- 脚注/尾注：根据学术规范或商业书惯例处理

**页眉页脚**：
- 页眉：书名（奇数页）/ 章节名（偶数页），或统一居中书名
- 页脚：居中页码

**封面与目录**：
- 封面页：书名、副标题、作者名
- 目录页：自动生成可点击目录

### 步骤七：交付可编辑成品

1. **Markdown 完整版**（`.md`）：纯文本，便于作者随时修改
2. **Word 出版版**（`.docx`）：含封面、目录、排版样式、插图
3. **封面源文件**（HTML + PNG）：可二次调整
4. **插图文件夹**：所有 AI 生成及作者提供的图片
5. **变更日志**（`changelog.md`）：记录素材与章节对应关系
6. **书籍定位说明书**：类型、读者、卖点、风格的完整记录

**声明**：全部文字、图片、封面均支持二次修改与替换，无任何锁定限制。

## 核心原则

1. **类型优先**：不同类型书籍遵循不同的结构逻辑和文风规范，禁止用同一套模板硬套所有书籍。
2. **作者主导**：结构、风格、视觉方向均由作者确认，Agent 只提供建议和执行。
3. **素材为基**：核心内容必须源于作者提供的素材或明确授权的创作方向。
4. **完全可编辑**：最终成品无任何锁定、水印或访问限制。
5. **灵活目标**：字数目标根据书籍类型合理设定，不盲目追求固定数字。
