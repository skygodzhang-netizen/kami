# 通用书籍创作助手 —— 参考文档

## 书籍类型速查表

| 类型 | 典型字数 | 核心结构 | 文风特征 | 目标读者 |
|------|---------|---------|---------|---------|
| 长篇小说 | 15-50万字 | 三幕式/英雄之旅 | 场景化、对话驱动 | 大众读者 |
| 中短篇小说集 | 8-15万字 | 主题串联/独立成篇 | 凝练、留白 | 文学爱好者 |
| 非虚构纪实 | 8-15万字 | 时间线/主题分类 | 客观、现场感 | 知识型读者 |
| 商业管理 | 6-12万字 | 框架-案例-工具 | 逻辑清晰、结论导向 | 职场人士 |
| 自助成长 | 6-10万字 | 痛点-方法-行动 | 共情、激励、步骤明确 | 寻求改变者 |
| 传记/回忆录 | 8-20万字 | 时间线+主题穿插 | 真实、人物立体 | 对人物/时代感兴趣者 |
| 学术专著 | 10-30万字 | 导论-文献-方法-结论 | 严谨、引用规范 | 同行学者 |
| 科普读物 | 6-12万字 | 问题-探索-解答 | 通俗、类比、趣味 | 普通大众 |

## 各类型结构模板

### 小说：三幕式结构模板

```
# 《书名》

## 第一幕：铺垫（约占25%）
- 第1章：日常世界（展示主角的生活状态）
- 第2章：触发事件（打破平衡的事件）
- 第3-5章：拒绝与犹豫（主角的反应，引入盟友/导师）
- 第6章：第一情节点（主角做出关键决定，进入新世界）

## 第二幕：对抗（约占50%）
- 第7-12章：探索新世界（尝试、失败、学习）
- 第13-15章：中期转折（发现真相，局势逆转）
- 第16-20章：压力升级（反派逼近，盟友受考验）
- 第21章：最低点（主角遭遇最大挫败）

## 第三幕：解决（约占25%）
- 第22-24章：觉醒与准备（主角重拾信念，制定计划）
- 第25-27章：最终对抗（高潮场景）
- 第28章：结局（新平衡建立，人物弧光完成）

## 人物设定表
| 人物 | 目标 | 恐惧 | 弧线（起点→终点） | 关系网 |
|------|------|------|------------------|--------|
| 主角 | | | | |
| 反派 | | | | |
| 导师/盟友 | | | | |
```

### 商业/管理：问题-框架-案例-工具结构

```
# 《书名》

## 第一部分：为什么（问题与趋势）
- 第1章：行业痛点/时代背景
- 第2章：传统方法的失效
- 第3章：新范式崛起的信号

## 第二部分：是什么（核心框架）
- 第4章：理论模型的提出
- 第5章：框架的构成要素
- 第6章：框架的适用边界

## 第三部分：怎么做（案例与实操）
- 第7章：案例A——某企业的成功实践
- 第8章：案例B——从失败中学习
- 第9章：案例C——中小企业的灵活运用
- 第10章：落地步骤与检查清单

## 第四部分：下一步（趋势与行动）
- 第11章：未来三年趋势预判
- 第12章：个人/企业的行动路线图

## 附录
- 工具清单
- 术语表
- 自检表
```

## 文风适配指南

### 小说文风检查清单
- [ ] 场景是否有五感描写（视、听、嗅、味、触）
- [ ] 对话是否符合人物身份和性格
- [ ] 是否有"展示"而非"告诉"（Show, don't tell）
- [ ] 章节结尾是否有悬念或情绪钩子
- [ ] 时间线和视角转换是否清晰
- [ ] 是否有冗余的形容词和副词可删减

### 非虚构文风检查清单
- [ ] 开头是否用场景/故事/悬念吸引读者
- [ ] 复杂概念是否有类比或例子解释
- [ ] 段落之间是否有清晰的逻辑过渡
- [ ] 数据和事实是否有来源标注
- [ ] 是否避免了过于学术化的表达
- [ ] 每章结尾是否有小结或思考题

### 商业/自助文风检查清单
- [ ] 每章是否有明确的"读者能获得什么"
- [ ] 方法论是否有步骤拆解
- [ ] 案例是否包含具体的公司/人名/数据
- [ ] 是否有可立即执行的行动建议
- [ ] 是否有视觉化工具（清单、表格、流程图）
- [ ] 语言是否简洁有力，避免冗余

## 封面设计指南（按类型）

### 视觉风格地图

| 类型 | 主色调 | 视觉元素 | 字体风格 | 情绪关键词 |
|------|--------|---------|---------|-----------|
| 悬疑小说 | 黑/深红/暗金 | 阴影、剪影、迷雾 | 锐利衬线体 | 神秘、紧张 |
| 言情小说 | 粉/暖白/淡金 | 花卉、城市剪影、光斑 | 优雅手写体 | 温暖、浪漫 |
| 科幻小说 | 蓝/紫/霓虹绿 | 星球、电路、几何 | 无衬线科技体 | 未来、冷峻 |
| 商业管理 | 深蓝/灰/金 | 极简图形、城市天际线 | 现代无衬线 | 专业、权威 |
| 自助成长 | 暖黄/绿/橙 | 阳光、植物、人物剪影 | 圆润无衬线 | 温暖、希望 |
| 传记 |  sepia/深褐/墨绿 | 老照片、档案、时间线 | 经典衬线体 | 厚重、真实 |
| 学术 | 藏蓝/深红/白 | 极简、机构徽章 | 传统衬线体 | 严谨、权威 |

### 封面文字层级
1. **书名**：最大字号，视觉中心，通常占封面高度的15-25%
2. **副标题**：书名的40-60%字号，解释价值主张
3. **作者名**：底部或侧边，清晰可辨
4. **推荐语/标签**（可选）：顶部或侧边，小字号

## 出版级排版规范

### 页面设置
- 纸张：A4（21cm × 29.7cm）
- 页边距：上/下 2.54cm，左/右 3.17cm（可调整为左3.5cm以预留装订空间）
- 方向：纵向

### 字体与段落
- 正文中文：宋体 10.5pt，1.5倍行距，首行缩进 0.74cm
- 正文英文：Times New Roman 11pt
- 一级标题（章）：黑体 18pt，段前36pt，段后18pt，**章前强制分页**
- 二级标题（节）：黑体 14pt，段前24pt，段后12pt
- 三级标题：黑体 12pt，段前18pt，段后6pt
- 引用块：楷体/斜体 10pt，左缩进1cm，段前段后6pt

### 页眉页脚
- 页眉：奇数页=章节名，偶数页=书名，宋体 9pt，灰色
- 页脚：居中页码，宋体 9pt，灰色
- 封面/目录页：不显示页眉页脚

### 特殊元素
- 插图：居中，宽度4-5英寸，图注居中、宋体9pt、灰色
- 表格：居中，表头加粗，表注居左、小字号
- 脚注：页面底部，8pt，短横线分隔
- 分隔符：三章之间可用装饰性分隔符或留白

## 技术实现参考

### python-docx 排版关键代码

```python
from docx import Document
from docx.shared import Pt, Cm, RGBColor, Inches
from docx.enum.text import WD_ALIGN_PARAGRAPH, WD_LINE_SPACING
from docx.oxml.ns import qn
from docx.oxml import OxmlElement

doc = Document()

# 页面设置
section = doc.sections[0]
section.page_height = Cm(29.7)
section.page_width = Cm(21.0)
section.top_margin = Cm(2.54)
section.bottom_margin = Cm(2.54)
section.left_margin = Cm(3.17)
section.right_margin = Cm(3.17)

# 中文字体设置函数
def set_run_font(run, font_name='宋体', font_size=Pt(10.5), bold=False, color=None):
    run.font.name = font_name
    run.font.size = font_size
    run.font.bold = bold
    if color:
        run.font.color.rgb = color
    r = run._element
    rPr = r.get_or_add_rPr()
    rFonts = OxmlElement('w:rFonts')
    rFonts.set(qn('w:eastAsia'), font_name)
    rPr.insert(0, rFonts)
```
