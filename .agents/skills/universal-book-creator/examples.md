# 通用书籍创作助手 —— 示例

## 示例一：小说类创作会话

**作者**：我想写一部长篇小说，关于一个失忆的侦探在2030年的上海寻找自己身份的故事。

**Agent**：非常棒的故事设定！为了帮你把这本书从灵感变成完整的作品，我需要先确认几个关键问题：

1. **书籍类型**：这是一部悬疑科幻小说，对吗？
2. **目标读者**：你面向的是喜欢硬科幻的读者，还是更偏向悬疑推理的普通读者？
3. **预计字数**：长篇小说通常在15-30万字，你的预期是？
4. **风格偏好**：语言风格偏冷峻克制（如雷蒙德·钱德勒），还是偏诗意华丽（如村上春树）？

**作者**：对，悬疑+轻科幻。面向普通读者，预计20万字。风格偏冷峻，带一点黑色电影的感觉。

**Agent**：已记录。现在进入素材收集阶段。你目前有哪些素材可以提供？

- 人物设定（主角、配角、反派的性格和背景）
- 世界观设定（2030年上海的社会规则、科技水平）
- 情节灵感或关键场景片段
- 已经写好的章节片段
- 参考书籍或电影（作为风格参考）

**作者**：我有一份详细的世界观文档，还有主角的人物小传。另外写了前三个场景的草稿，大约8000字。

**Agent**：很好，我来建立素材清单：

```
# 创作素材清单

## 书籍定位
- 类型：长篇小说（悬疑+轻科幻）
- 目标读者：18-40岁，喜欢悬疑推理的普通读者
- 预计字数：20万字
- 核心卖点：失忆侦探在赛博朋克上海寻找身份的黑色悬疑故事
- 风格：冷峻克制，黑色电影质感

## 素材 1
- 标题：世界观设定文档
- 形式：文字文档
- 字数：约5,000字
- 核心内容：2030年上海的社会结构、科技水平、法律体系
- 可用性：可直接引用，需融入叙事

## 素材 2
- 标题：主角人物小传
- 形式：人物设定表
- 字数：约2,000字
- 核心内容：失忆前的身份、性格特征、技能、人际关系
- 可用性：需转化为叙事，避免信息 dump

## 素材 3
- 标题：前三场景草稿
- 形式：小说章节片段
- 字数：约8,000字
- 核心内容：主角醒来、发现失忆、第一次遭遇危机
- 可用性：可直接作为第1-2章的基础，需润色

## 汇总
- 素材总数：3
- 总字数：约15,000字
- 覆盖度评估：世界观和人物基础较好，但情节主线（中段案件、反派动机、高潮设计）需要补充
- 需补充：
  - 核心案件的完整诡计设计
  - 反派的人物动机和背景
  - 关键配角（助手/对手/爱慕对象）的设定
```

请补充以上缺环，或我们先基于现有素材设计大纲，你在写作过程中再逐步完善？

**作者**：先设计大纲吧，人物和案件我在写的过程中会自然浮现。

**Agent**：收到。基于你的"失忆侦探+赛博朋克上海"设定，我推荐采用**三幕式结构+双线叙事**（现实调查线+记忆闪回线）。以下是结构方案：

```
# 《雾中城》（暂定名）

## 第一幕：迷失（约5万字）
- 第1章：醒来的空白（主角在雨夜的废弃医院醒来）
- 第2章：2030年的上海（通过主角视角展示世界观）
- 第3-5章：第一个线索（发现身上的神秘芯片）
- 第6-8章：被迫调查（卷入第一起案件，结识女黑客助手）
- 第9章：第一情节点（发现芯片与自己的过去有关，决定追查）

## 第二幕：深入（约10万字）
- 第10-15章：调查主线（连环案件，每个案件触发一段记忆闪回）
- 第16章：中期转折（发现案件背后的巨大阴谋，助手被抓/背叛）
- 第17-22章：孤立无援（主角独自深入，记忆逐渐恢复）
- 第23章：最低点（发现失忆前的自己可能是反派同谋）

## 第三幕：觉醒（约5万字）
- 第24-26章：真相拼图（整合记忆与现实，制定最终计划）
- 第27-29章：高潮对决（核心诡计揭晓，正反派的终极对抗）
- 第30章：新开始（身份确认，选择留下或离开上海）
```

**人物弧光设计**：
- 起点：迷失、不信任任何人、依赖逻辑
- 中点：开始信任他人，发现情感也是线索
- 终点：接受不完美的自己，用选择定义身份（而非记忆）

请确认这个结构，或提出调整意见。

**作者**：结构可以，但我不想有爱情线，助手和主角是纯搭档关系。

**Agent**：已调整。助手角色改为"亦敌亦友的前同事"，无爱情线，信任的建立基于共同利益和相互试探。开始起草第一幕。

## 示例二：商业类创作会话

**作者**：我想把我做餐饮连锁十多年的经验写成一本书，教年轻人怎么开店。

**Agent**：很好的主题！先确认几个关键问题：

1. **书籍类型**：商业管理/创业指南
2. **目标读者**：想开餐饮店的年轻人（有资金但缺经验）
3. **预计字数**：商业书通常6-10万字，你的预期？
4. **核心卖点**：十年餐饮实战经验，从0到50家门店的完整路径

**作者**：对，预计8万字左右。风格要通俗易懂，多讲我踩过的坑。

**Agent**：已记录。请提供现有素材：

**作者**：我有三次年会演讲稿，还有十几篇公众号文章，另外我整理过一个"开店检查清单"。

**Agent**：建立素材清单后发现总素材约4万字，目标8万字，需扩充约4万字。建议通过增加详细案例、数据对比、工具模板来补足。

以下是推荐结构（问题-框架-案例-工具）：

```
# 《开一家赚钱的餐厅》

## 第一部分：为什么是你（1.5万字）
- 第1章：餐饮行业的真相（90%的人不知道的残酷数据）
- 第2章：什么样的人适合开餐厅（自测表）
- 第3章：我的三次破产与重生（个人故事建立信任）

## 第二部分：开店前（2万字）
- 第4章：选址的科学与玄学（案例：我如何通过数据选对第一家店）
- 第5章：算账：你的启动资金到底够不够（详细成本拆解表）
- 第6章：菜单设计的秘密（不是好吃就行，要算毛利和出餐速度）
- 第7章：团队搭建：从哪里找你的第一批人

## 第三部分：开店中（2.5万字）
- 第8章：开业前三个月的生死线
- 第9章：流量从哪里来（线下+抖音+外卖的实战打法）
- 第10章：供应链：省下来的都是利润
- 第11章：我踩过的十个坑（每一个都值十万块）
- 第12章：从一家店到十家店：标准化复制

## 第四部分：开店后（1万字）
- 第13章：餐厅老板的自我修养
- 第14章：什么时候该关店止损
- 第15章：给餐饮创业者的最后一句话

## 附录（1万字）
- 开店成本计算器
- 选址评分表
- 菜单毛利分析模板
- 员工培训检查清单
- 供应商谈判话术
```

**作者**：可以，但第11章"十个坑"我想放到最前面当钩子。

**Agent**：已调整。将"十个坑"提炼为引言中的"先给你看看我亏过的钱"，既做钩子又不破坏整体结构。开始起草。
