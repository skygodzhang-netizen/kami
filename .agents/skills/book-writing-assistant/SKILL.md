# 智能写书助手

## 技能定位

本技能帮助作者将分散的原创文字素材整理为结构完整、字数达标（不低于10万字）的书籍成稿，并配套AI插图生成、畅销书封面设计和出版级页面排版。全程严格依托作者提供的原始内容，确保最终书稿支持完全自定义编辑。

## 工作流程

按以下清单逐步执行并跟踪进度：

```
任务进度：
- [ ] 步骤一：收集原创素材
- [ ] 步骤二：分析梳理并拟定大纲（含字数规划）
- [ ] 步骤三：分章起草正文（确保总字数≥10万字）
- [ ] 步骤四：生成AI插图
- [ ] 步骤五：设计畅销书封面
- [ ] 步骤六：出版级页面排版
- [ ] 步骤七：汇编完整书稿
- [ ] 步骤八：交付可编辑成品
```

### 步骤一：收集原创素材（强制触发）

在正式起草任何内容前，Agent须主动引导作者提交全部原创参考素材：

- 演讲稿、讲座稿或发言记录
- 日常笔记、日记或随笔
- 已发表的文章、散文或博客
- 碎片化草稿或大纲
- 行业资料、研究报告或读书笔记
- 其他任何作者原创的文字内容

**操作要求**：为所有收集到的素材建立编号清单，请作者确认清单完整后方可进入下一步。

**强制约束**：未收集并清点至少一份原创素材前，禁止开始任何章节起草。

### 步骤二：分析梳理并拟定大纲（含字数规划）

1. 从已收集素材中提取核心观点、关键论据与叙事主线。
2. 识别逻辑缺环，向作者提出澄清问题。
3. 基于素材的自然脉络，提出书籍结构方案（部、章、节）。
4. **字数规划**：根据目标10万字总量，为每个章节分配建议字数。若原始素材不足，须在大纲阶段规划扩充方向（如新增章节、案例深度、附录工具包等）。
5. 等待作者确认或调整后再进入起草阶段。

**强制约束**：大纲必须反映作者的原始意图，禁止编造素材中未支撑的新主题。

### 步骤三：分章起草正文（确保总字数≥10万字）

针对每一章已确认的内容：

1. 选取与之相关的原始素材。
2. 对素材进行重组、改写与衔接，形成连贯叙述。
3. 全书保持统一的文风与术语体系。
4. **字数达标策略**：
   - 常规章节：每章5000-8000字
   - 重点章节：每章8000-12000字
   - 案例/实战章节：通过详细案例描述、步骤拆解、对话还原充实内容
   - 附录章节：术语表、工具清单、自检表、模板库等实用内容扩充
   - 若素材不足，通过以下方式扩充：
     - 增加亲历案例（基于作者身份设计真实场景）
     - 增加行业对比与趋势分析
     - 增加实操指南与避坑清单
     - 增加附录工具包（术语表、工具清单、模板、自检表等）
5. 对需要作者补充或确认的位置标记 `[TODO：请作者审阅]`。
6. 将本章草稿提交作者反馈，确认后再进入下一章。

**强制约束**：每一个关键论点都必须能在作者原始素材中找到来源。允许转述与综合，但禁止虚构事实或杜撰引语。

**字数检查**：每完成一批章节，须统计累计字数并向作者报告进度，确保全书最终不低于10万字。

### 步骤四：生成AI插图

当作者提出插图需求或Agent判断某章需要视觉辅助时：

1. 分析该章的核心场景、关键概念、情绪基调或转折时刻。
2. 撰写符合全书整体风格的高清插图生成提示词。
3. 生成图片并作为**草稿占位图**呈现。
4. 为每张插图明确标注：`插图【第X章】：描述（草稿——可替换）`。
5. 将插图直接插入到排版后的Word文档对应位置。

**作者权限**：作者可随时将任意AI插图替换为自定义图片、原创手绘、商用配图等任意合规图片。

**强制约束**：插图必须直接反映对应章节内容，禁止使用与内容无关的纯装饰性图片。

### 步骤五：设计畅销书封面

正文完稿后，为书籍设计一套符合市场审美的封面：

1. **风格定位**：根据书籍主题和目标读者，确定封面风格（如科技霓虹、商务极简、人文温暖等）。
2. **视觉生成**：使用ImageGen生成高质量封面底图，要求：
   - 竖版比例（2:3或3:4，适合书籍封面）
   - 主题明确、色彩鲜明、视觉层次丰富
   - 符合当下年轻读者审美趋势
3. **文字合成**：使用HTML/CSS将书名、副标题、作者名等文字与底图合成，确保：
   - 标题醒目、字体现代、排版有设计感
   - 文字与背景对比度足够，保证可读性
   - 整体呈现出"畅销书"质感
4. 提供封面源文件（HTML+背景图），方便作者后续调整。

**强制约束**：封面设计须同时提供纯背景图和带文字的合成封面，作者拥有完全修改权。

### 步骤六：出版级页面排版

书稿汇编前，完成专业的出版级排版：

1. **页面设置**：A4纸张，标准书边距（上下2.54cm，左右3.17cm）。
2. **字体规范**：
   - 正文：宋体 10.5pt，1.5倍行距，首行缩进0.74cm
   - 一级标题：黑体 18pt，章前分页
   - 二级标题：黑体 14pt
   - 三级标题：黑体 12pt
3. **页眉页脚**：
   - 页眉居中显示书名
   - 页脚居中显示页码
4. **插图排版**：
   - 插图居中显示，宽度适中
   - 图注使用小字号、居中、灰色
5. **封面插入**：在文档首页插入封面页（书名、作者、副标题）。
6. **目录页**：生成可点击的目录页。

**技术实现**：使用 `python-docx` 库进行自动化排版，确保样式统一、格式规范。

### 步骤七：汇编完整书稿

1. 按顺序汇总所有已确认章节。
2. 在合适位置插入已确认或草稿状态的插图。
3. 添加封面页、目录页。
4. 添加前辅文（作者自序等，如作者提供）和后辅文（结语、致谢、附录等）。
5. 执行一致性检查：术语、人名、时间线、文风。
6. **最终字数核验**：确认全书总字数不低于10万字。

### 步骤八：交付可编辑成品

1. 以通用可编辑格式导出书稿：
   - Markdown完整版（`.md`）：便于作者随时修改
   - Word出版版（`.docx`）：含封面、目录、排版、插图
2. 将所有插图（AI生成及作者提供）单独存放于 `illustrations/` 文件夹。
3. 提供封面设计源文件（HTML+背景图）。
4. 提供变更日志，注明原始素材与章节内容的对应关系。
5. 向作者明确声明：全部文字、图片、封面均支持二次修改、替换与微调，无任何锁定限制。

## 核心原则

1. **原创忠实**：书籍以作者自身的文字与思想为唯一创作基底，Agent仅承担组织与编辑角色，不进行脱离素材的虚构创作。
2. **作者主导**：每一处结构决策、风格选择与插图方案均需经过作者确认。
3. **完全可编辑**：最终成品不设置任何锁定、水印或访问限制。
4. **字数达标**：全书最终字数必须达到或超过10万字，不足时须通过扩充案例、增加章节、丰富附录等方式补足。
5. **一站式交付**：从素材到成书，从内容到排版，从插图到封面，作者只需提供素材和确认方向，Agent完成全部执行工作。
