# Book Writing Assistant（智能写书助手）

一个 QoderWork / OpenClaw Agent Skill，帮助作者将分散的原创文字素材整理为结构完整、字数达标（不低于10万字）的书籍成稿，并配套 AI 插图生成、畅销书封面设计和出版级页面排版。

## 功能特性

- **原创素材驱动**：严格依托作者提供的演讲稿、笔记、文章等原始内容创作
- **字数强制达标**：全书最终字数不低于10万字，提供多种扩充策略
- **AI 插图生成**：根据章节内容自动生成匹配的内页插图草稿
- **畅销书封面设计**：科技霓虹/极简/人文等多种风格，HTML/CSS 可编辑源文件
- **出版级 Word 排版**：A4 页面、标准中文字体、页眉页脚、自动目录、插图排版
- **一站式交付**：从素材到成书，从内容到封面，全程自动完成

## 工作流程

1. **收集原创素材** —— 清点并确认作者提供的全部原始文字
2. **分析梳理并拟定大纲** —— 提取主线，规划结构，分配字数
3. **分章起草正文** —— 逐章创作，确保总字数≥10万字
4. **生成 AI 插图** —— 为关键章节生成配套插图
5. **设计畅销书封面** —— 生成封面底图 + HTML/CSS 文字合成
6. **出版级页面排版** —— python-docx 自动化排版
7. **汇编完整书稿** —— 汇总全部章节、插图、附录
8. **交付可编辑成品** —— Markdown + Word + 封面源文件 + 变更日志

## 安装方法

### QoderWork 用户

将 `.skill` 文件放入 QoderWork 的 skills 目录即可自动识别。

### OpenClaw 用户

1. 下载本仓库的 `.skill` 文件
2. 在 OpenClaw 中选择 **安装 Skill → 从本地文件安装**
3. 选择 `book-writing-assistant.skill` 完成安装

或者通过 Git 地址直接安装：

```
/skill install https://github.com/你的用户名/book-writing-assistant
```

## 使用场景

- 将多年演讲稿、博客文章整理成系统化的专业书籍
- 为企业家、咨询师、技术专家打造个人 IP 专著
- 快速生成包含实战案例、工具清单、模板的实用性图书
- 需要配套插图、封面和出版级排版的完整书稿项目

## 核心原则

1. **原创忠实**：以作者自身文字与思想为唯一创作基底
2. **作者主导**：每一处结构、风格、插图方案均需作者确认
3. **完全可编辑**：最终成品无任何锁定、水印或访问限制
4. **字数达标**：全书最终字数必须达到或超过10万字
5. **一站式交付**：内容、插图、封面、排版全部自动完成
