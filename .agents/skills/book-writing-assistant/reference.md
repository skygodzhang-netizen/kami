## 字数规划与达标指南

### 10万字分配模型

| 内容模块 | 建议章节数 | 单章字数 | 小计 |
|---------|-----------|---------|------|
| 引言/前言 | 1 | 3,000-5,000 | 4,000 |
| 正文（核心） | 12-16 | 5,000-8,000 | 80,000-100,000 |
| 结语 | 1 | 2,000-3,000 | 2,500 |
| 附录（工具包） | 3-5 | 2,000-5,000 | 10,000-15,000 |
| **合计** | **17-23** | - | **≥100,000** |

### 字数扩充策略

当原始素材不足以支撑10万字时，采用以下策略：

1. **增加亲历案例**：基于作者身份设计真实场景，每案例约1,500-3,000字
2. **增加实操指南**：步骤拆解、避坑清单、对照表格，每节约1,000-2,000字
3. **增加趋势分析**：行业对比、数据引用、未来展望
4. **增加附录工具包**：
   - 术语速查表（2,000-3,000字）
   - 实用工具清单（3,000-5,000字）
   - 自检表/模板（1,000-3,000字）
   - 万能提示词/脚本（2,000-5,000字）
5. **增加新章节**：根据主题延伸3-5个新增章节

### 字数统计方法

- 使用Python脚本统计中文字符数（去除markdown标记和空格）
- 每完成一批章节报告累计进度
- 最终交付前执行全书字数核验

## 插图风格指南

撰写插图生成提示词时须包含以下要素：

1. **主体**：章节中确切的场景、物体或概念。
2. **氛围**：情绪基调（如沉思、激昂、庄重）。
3. **风格**：艺术方向（如水彩、数字插画、极简线稿、照片写实）。
4. **配色**：与全书视觉主题一致的主色调。
5. **构图**：画框、视角与视觉焦点。

**提示词示例结构**：
```
一幅【风格】插画，描绘【主体】，【氛围场景】，
采用【配色】，【构图细节】，
高细节，书籍内页插图风格
```

## 畅销书封面设计指南

### 设计流程

1. **确定风格方向**
   - 科技/商业类：霓虹渐变、几何线条、深蓝/紫/青配色
   - 人文/成长类：温暖色调、手绘插画、自然元素
   - 极简/高端类：大面积留白、单色调、精致字体

2. **生成背景图**
   - 尺寸：竖版（推荐1024×1536，即2:3比例）
   - 要求：主题明确、层次分明、留有标题空间
   - 使用ImageGen生成，提示词须包含"book cover design, premium editorial style"

3. **文字合成**
   - 使用HTML/CSS合成最终封面
   - 标题：大字号、粗体、渐变或发光效果
   - 副标题：中等字号、与主标题形成层次
   - 作者名：底部居中或右下，字号适中
   - 装饰：英文副标题、细线分隔、角标装饰

4. **输出规格**
   - 提供纯背景图（PNG）
   - 提供带文字合成封面（HTML文件，可在浏览器中截图保存）

### 年轻人审美要点

- 渐变色优于纯色
- 大字号标题+适度留白
- 微动效/发光感增加科技感
- 字体现代简洁（无衬线或黑体）
- 避免陈旧、 cluttered 的设计

## 出版级排版规范

### 页面设置
- 纸张：A4（21cm × 29.7cm）
- 页边距：上/下 2.54cm，左/右 3.17cm
- 方向：纵向

### 字体与段落
- 正文：宋体 10.5pt，1.5倍行距，首行缩进0.74cm
- 一级标题（章）：黑体 18pt，段前36pt，段后18pt，**章前强制分页**
- 二级标题（节）：黑体 14pt，段前24pt，段后12pt
- 三级标题：黑体 12pt，段前18pt，段后6pt
- 列表项：左缩进0.74cm，首行无缩进

### 页眉页脚
- 页眉：居中显示书名，宋体 9pt，灰色（#888888）
- 页脚：居中显示页码，宋体 9pt，灰色

### 插图排版
- 图片居中，宽度适中（建议4-5英寸）
- 图注：居中，宋体 9pt，灰色（#666666）
- 图注格式：`图X-Y  描述文字`

### 代码块排版
- 等宽字体（Consolas），9pt
- 左缩进1cm，段前段后6pt
- 单倍行距
- 灰色文字（#333333）

### 封面页
- 书名：黑体 26pt，居中，段前120pt
- 副标题：楷体 14pt，居中，灰色
- 作者名：宋体 12pt，居中，段前60pt

### 目录页
- "目录"标题：黑体 22pt，居中
- 部标题：黑体 12pt，段前12pt
- 章标题：宋体 10.5pt，段前3pt

## 技术实现参考

使用 `python-docx` 库实现自动化排版：

```python
from docx import Document
from docx.shared import Pt, Cm, RGBColor, Inches
from docx.enum.text import WD_ALIGN_PARAGRAPH, WD_LINE_SPACING
from docx.oxml.ns import qn
from docx.oxml import OxmlElement

# 关键设置示例
doc = Document()
section = doc.sections[0]
section.page_height = Cm(29.7)
section.page_width = Cm(21.0)
section.top_margin = Cm(2.54)
section.bottom_margin = Cm(2.54)
section.left_margin = Cm(3.17)
section.right_margin = Cm(3.17)

# 设置中文字体
def set_run_font(run, font_name='宋体', font_size=Pt(10.5)):
    run.font.name = font_name
    run.font.size = font_size
    r = run._element
    rPr = r.get_or_add_rPr()
    rFonts = OxmlElement('w:rFonts')
    rFonts.set(qn('w:eastAsia'), font_name)
    rPr.insert(0, rFonts)
```

## 可编辑输出规范

### 文字
- 首选格式：Markdown（`.md`），兼容性最佳
- 出版格式：Word（`.docx`），含完整排版样式
- 样式使用语义化标记（标题、引用、强调），避免硬编码格式

### 图片
- 格式：PNG 或 JPEG，300 DPI 印刷级品质
- 命名规则：`illust-chXX-YYYY-MM-DD.png`
- 存放位置：独立 `illustrations/` 文件夹
- 元数据：文件名或配套 JSON 中注明图注与对应章节

### 封面
- 背景图：PNG，竖版比例
- 合成封面：HTML文件（含CSS样式）
- 字体文件：建议使用系统默认字体或开源字体

### 变更日志
- 维护 `changelog.md`，记录原始素材与章节内容的对应关系
- 示例条目：`第三章第2节 -> 源自"演讲稿_2024_科技大会.md"第12-28段`
